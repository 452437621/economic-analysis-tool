## 1. 这是什么

EPIC 是一个本地运行的个人市场分析工作台：

```text
官方新闻/宏观数据/行情
        ↓
证据链（正文 + 断言 + 精确引用）
        ↓
分析引擎（周期/归因/相关性/风向/类比/领先滞后/事件研究）
        ↓
决策系统（信号 → 风控计划 → 论点/情景 → 预测 → 回测 → 复核）
        ↓
每日简报 / 周报 / 月报 / 告警 / 交易日志
```

目标：把「信息 → 证据 → 判断 → 计划 → 复盘」固化成每天可重复的流程，而不是追逐消息。

## 3. 数据源与已知限制

| 数据 | 来源 | 限制 |
|---|---|---|
| 国内期货/A股 | 新浪、东财 | 实时/延迟；A股仅沪深300与洛阳钼业 |
| 外盘商品/汇率 | 新浪 hf/fx、东财 | 外盘约 15 分钟延迟；LME 铝锌镍仅报价无日线 |
| 全球股指 | 东财（SPX/NDX/DJIA/HSI） | 约 15 分钟延迟 |
| 美债/日债/德债/中国国债 | 美国财政部、日本财务省、ECB、东财 | 日频；中国曲线由东财转发 |
| 宏观/日历 | 东财日历、国家统计局 RSS | 官方 CPI/PMI 数值仍靠规则断言，非结构化 API |
| 新闻 | 美联储/ECB/BOJ/EIA/USTR/NBS | 美国财政部页面改版失效；NBS 走低频 |
| 会员持仓 | 上期所/郑商所官方、新浪（大商所） | 仅 Top20；大商所为页面抓取 |
| CFTC/ETF/FRED/BLS | — | 国内直连 403/超时，未接入 |

**其他限制**：市场隐含周期置信度 0.35–0.40；历史类比样本有限；回测未覆盖全部交易成本；信号/事件方向含规则启发式；所有计划为草稿。

## 5. 安装与启动

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -File .\scripts\start.ps1
# http://127.0.0.1:8765
```

自检：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\selfcheck.ps1
```

配置：复制 `.env.example` 为 `.env`，按需填 LLM Key、账户权益/风险%、告警渠道。

## 6. 需要用户完成的事（M6 试运行）

1. 每天看板 20–30 分钟：简报 → 分析 → 计划/论点 → 交易日志。
2. 每周日看周报、每月 1 日看月报，记录校准项。
3. 提供 **DeepSeek API Key**（LLM 抽取/简报/论点证据）。
4. 确认 **账户权益与单笔风险%**（当前 100 万 / 0.25%，导致 AG/CU 无法开 1 手）。
5. 提供期货公司**实际保证金/手续费**（替换交易所近似值）。
6. 可选：告警渠道凭据（Server 酱/企业微信/SMTP）。

试运行记录模板与周度校准方法见 [09 试运行与验收](./09-试运行与验收.md)；每日执行清单见 [11 M6 试运行清单](./11-M6试运行清单.md)。
