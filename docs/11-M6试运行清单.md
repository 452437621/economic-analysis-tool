# 11 M6 试运行清单（可打印）

> 用途：2 周试运行期间每天/每周照着做，减少遗漏；最后用第 4 节标准判断是否可进入 V1.1。
> 原则：**先看证据，再看观点；先写判断，再看结果；计划只是草稿。**

---

## 1. 每日（约 15–25 分钟）

### 盘前 07:30–09:00

- [ ] 打开看板（http://127.0.0.1:8765），确认顶部状态「运行中」。
- [ ] **告警**：逐条读，点「确认」；记录误报。
- [ ] **简报 → 主次动力**：记下前 3 条动力，写下你是否同意（1 句话）。
- [ ] **市场快照**：看前 5 个波动品种；注意数据时点/延迟标签。
- [ ] **持仓结构**：看净多/净空 Top3；标记与价格趋势相反的品种。
- [ ] **事件驱动 / 财经日历**：今天有哪些高影响事件？时间点？
- [ ] **交易信号与计划**：看手数/保证金/风控；被拦截的计划写原因。
- [ ] **论点与情景**：是否有新论点？失效条件是否清楚？

### 盘中（可选，2–3 次）

- [ ] 看告警是否有新的价格异动/日历提醒。
- [ ] 不因单条消息临时改计划；要改先写日志。

### 盘后 15:30–21:30

- [ ] 看盘后简报/最新数据。
- [ ] 在「交易日志」写 3–5 行：
  - 今日主线：
  - 系统判断 vs 我的判断：
  - 计划执行/放弃及原因：
  - 情绪与错误：
- [ ] 记录当日「系统对/错」各 1 条（用于周度校准）。

---

## 2. 每周日（30–45 分钟）

- [ ] 打开「简报 → 周报」。
- [ ] 填校准表（第 3 节）。
- [ ] 回看本周交易日志，统计：
  - 计划采纳 __ / 修改 __ / 拒绝 __；
  - 告警有效 __ / 误报 __；
  - 论点新增 __ / 失效 __。
- [ ] 调整 1 个参数（来源权重/告警阈值/风险比例），并写理由。
- [ ] 运行 `scripts\selfcheck.ps1`，确认无失败项。

## 4. 两周后判断标准（M6 出口）

达到以下条件，才进入 V1.1 迭代：

- [ ] 至少 **8 个交易日**按清单完整使用；
- [ ] 交易日志 ≥ 8 篇，且包含「系统 vs 人工」差异；
- [ ] 累计 **20 条以上**明确修正记录（判断/参数/数据）；
- [ ] 预测账本有 **≥5 条已结算**，能算出 Brier；
- [ ] 告警误报率可量化，且可接受（目标 < 30%）；
- [ ] 没有因系统故障导致的重大漏看/误操作；
- [ ] 明确 V1.1 的 3 个优先项。

未达到：继续试运行，不急着加功能。

---

## 5. 红灯（立即处理）

| 现象 | 处理 |
|---|---|
| 顶部状态「降级」/ API 500 | 看日志、跑 `selfcheck.ps1`、必要时恢复备份 |
| 行情长期不更新（>1 交易日） | 看「数据源健康」与任务状态，手动 `--job collect_quotes` |
| 简报/日历为空 | 检查采集任务与数据质检；看事件/日历任务 |
| 计划手数长期为 0 | 复核账户权益/风险比例/合约参数 |
| 告警刷屏或长期静默 | 检查阈值与去重窗口，记录误报样本 |
