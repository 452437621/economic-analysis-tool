## 2. M6 试运行计划（2 周）

### 2.1 每日记录模板

```markdown
## YYYY-MM-DD
- 盘前阅读：__ 分钟；人工修正：__ 处
- 系统主线 vs 我的判断：一致/部分/相反；原因：
- 交易计划：采纳 __ 份 / 修改 __ 份 / 拒绝 __ 份；理由：
- 告警：__ 条；有效 __ 条；误报 __ 条
- 重大事件与系统覆盖：__（是否捕获、证据是否够）
- 明日关注：
```

### 2.2 周度校准

| 项 | 方法 | 目标 |
|---|---|---|
| 来源可信度 | 人工核对 30 条断言，标记正确/错误，回填来源权重 | 错误率 < 10% |
| 周期权重 | 对比市场隐含象限与实际资产表现，调整增长/通胀权重 | 方向命中 > 55% |
| 信号参数 | 对比回测与实盘观察，检查突破/动量/均值回归触发质量 | 减少无效信号 |
| 告警阈值 | 统计误报率，调整 3%/5% 与陈旧阈值 | 误报 < 30% |
| 简报可用性 | 1–5 分评分 + 修改量 | ≥ 4 分 |

### 2.3 试运行产出

- 两周决策日志（系统建议 vs 人工判断 vs 实际结果）；
- 校准后的配置（`.env`、`config/default.yaml`、`CONTRACT_SPECS`）；
- V1.1 需求清单（是否接入付费数据/自动交易/移动端）。

## 4. 安全与合规复核

| 项 | 现状 | 结论 |
|---|---|---|
| 监听地址 | `127.0.0.1`，无公网暴露 | 符合个人使用 |
| 密钥 | `.env` 不入库；`.gitignore` 已排除；日志不打印密钥 | 符合 |
| 数据版权 | 仅官方/公开源；新闻仅标题与元数据 + 官方正文；不抓 Reuters/Bloomberg 正文 | 符合个人研究 |
| LLM 数据 | 仅发送官方公开文本；不发送账户/个人数据 | 待启用后复核 |
| 投资建议 | 看板/简报/导出均含免责声明；计划标注「草稿，需人工确认」 | 符合 |
| 自动交易 | 不接任何交易接口，不下单 | 符合 V1 边界 |
| 依赖安全 | 版本锁定于 `.venv`；建议定期 `pip audit` | 待例行化 |
| 备份 | `backup.ps1` 热备 SQLite + 配置 | 已具备；建议每周演练 |
