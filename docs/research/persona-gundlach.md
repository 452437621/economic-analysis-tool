## 1. 结论（8 条，每条一句话，直接给判断与交易/政策含义）

1. **利率是第一分析对象，且长端已不由美联储定价。** 10Y 5.07%（2015 年以来 98 分位）、实际 10Y 2.89%（区间 99 分位），上行几乎全部来自实际利率与供给/期限溢价而非通胀预期——做多久期要等价格，不要等降息。
2. **10Y 的「公允区间」是 4.9%–6.0% 的双模型区间，不是点。** 混合模型 4.9% 已到、名义 GDP 模型 6% 未到——5% 附近不追多也不追空，`US10Y ≥ 6.0%` 或 `US30Y ≥ 6.5%` 才是他定义的买点。
3. **曲线形态必须先分解主导因子再交易。** 熊陡=财政/通胀溢价（低配 30Y、多 TIPS 与黄金）；牛陡=衰退定价（加 5Y 久期、减信用）——同为「陡峭化」，资产方向相反。
4. **信用周期被延后但没被取消。** 再融资墙加私募信贷/CLO/保险的不透明估值，把清算推到下一次下行；CCC 与 AI 相关利差是裂缝的领先读数，本地无 HY OAS，只能用「股票跌幅+铜金比」代理。
5. **美元进入结构性弱周期，且衰退时不再避险。** 赤字 6.86% GDP、利息/收入 19.8%（TTM）是燃料；但 2026 年 DXY 从 96.35 反弹到 103.9（+7.9%）说明「结构性」不等于「直线」——用 60 日动量确认，不用叙事扛仓位。
6. **黄金已从「实际利率的函数」变成「货币/储备资产」。** 他给过 25% 配置与 4,000 目标；2026-01-28 见顶 5,414.84 后跌 31% 至 3,733，正是「长期基石、不追高、等 4,000 下方」的用法，而不是「永远满仓」。
7. **股债同向（60 日相关 +0.10，落在正值区间）意味着 60/40 失效。** 配置应是杠铃：短久期高质量债 + 实物资产约 20% + 等权股票 + EM 本币债；股票的问题是 CAPE 42 的估值问题，不是盈利问题。
8. **美联储是跟随者：`US2Y − EFFR` 是反应函数的充分统计量。** 当前 +92bp（2025 年降息期是 −70bp），意味着市场在定价再加息——任何「降息交易」都逆着这条规则，也解释了他 2026-03 加息判断对、2026-09-11 直播判断错。

## 2. 框架与世界观（利率定价三因子：实际增长/通胀预期/期限溢价；曲线形态学；信用周期）

### 2.1 三因子：不是「Fed 路径的贴现」，而是「实际利率 + 通胀预期 + 期限溢价」

冈拉克的恒等式版本：

```
US10Y ≈ r*（实际增长/实际利率） + π^e（通胀预期） + TP（期限溢价）
TP ≈ f(净供给, 海外需求, 财政可持续性, 利率波动率)
```

本地读数（2026-11-18）：实际 10Y `US10Y_REAL` = 2.89%（2015 以来 99 分位，区间上限 2.95%）；通胀预期 `US10Y_BE` = 2.21%（温和）；期限溢价粗代理 `US10Y − US2Y − (US10Y_BE − 2%)` ≈ **+6bp**。结论：这一轮上行是**实际利率 + 供给**的故事，不是通胀恐慌的故事——这正是他在通胀预期 2.2% 时仍看空长端的底气，也是他与「通胀交易者」的分歧点。

### 2.2 双模型公允区间：4.9% 与 6.0%

他在 2026-09-25 录制、10-06 发表的 UBS 专访里给了两个模型（E2）：

- **模型 A（名义 GDP 锚）**：七年名义 GDP 均值约 6.1% → 10Y 理论上可到 6%。本地可算：`WB_US_GDP` 同比（年度）七年均值（滞后约 1 年）。
- **模型 B（混合锚）**：名义 GDP 与德国 10Y 混合 → 公允约 4.9%，当时 10Y 约 5.1%，高约 25bp。

框架含义：**公允值是区间、且模型本身有 ±100bp 的不确定性**。区间内做趋势跟随（他 2026 全年「最小阻力路径向上」），区间上沿才做反转（「10Y 到 6%、30Y 到 6.0–6.5% 我才买长债」）。不要把他的「公允值」当均值回归目标——他 2022-12 给 10Y 公允 2%–2.5%，事后错得离谱；此后他改为给区间/多模型表述（【推断】：这一转变未见本人明确说明，是从 2023 年后的发言形态归纳的）。

### 2.3 曲线形态学：四象限先定形态，再看谁在动

| 2s10s | 30s10s | 形态 | 主导因子 | 交易含义 |
|---|---|---|---|---|
| < 0 | > 0 | 倒挂但长端陡 | 政策限制性 + 期限溢价已转正 | 中段久期最差，长端有溢价补偿 |
| < 0 | ≤ 0 | 全面倒挂 | 衰退临近（他 2023 全年主判断） | 加久期要等「去倒挂」确认 |
| > 0 且走阔 | 走阔 | 熊陡 | 长端供给/通胀溢价 | 低配 30Y，多 TIPS/黄金 |
| > 0 且走阔 | 收窄 | 牛陡 | 短端崩、降息定价 | 加 5Y 久期，减信用与周期股 |
| > 0 | 收窄至 ≤ 0 | 平坦化（牛平/熊平） | 周期后段 | 减风险资产，等下一轮 |

判别要点：**同为「陡峭化」，看 2Y 与 10Y 谁在动**。`Δ20d(2s10s)` 与 `Δ20d(30s10s)` 同号放大 → 熊陡；2s10s 走阔而 30s10s 收窄 → 牛陡（衰退）。

### 2.4 信用周期：延后，而非取消

他的信用框架只有三句话：

1. **再融资墙**：2020–2021 年低息发行的债在 2024–2027 年到期，高利率下再融资 → 违约率上行（2023-03 原话：若经济在高利率与弱增长中挣扎，将出现「史上最高违约率」）。
2. **延后机制**：私募信贷、CLO、保险三方把风险从公开利差转移到不透明估值里，公开市场看不到，于是「周期被延后」（他 2023 年就承认 "The cycle has been delayed"）。
3. **清算时点不可预测，但裂缝可观测**：CCC 与 AI 相关利差先走阔，评级机构仍在上调 CLO 评级（2026-07 的 "disconnect"）——这是他认为的「引信」，保险是「炸弹」。

### 2.5 水床难题：反应函数里多了一个财政约束

```
压通胀（加息/维持高利率） → 利息支出↑ → 赤字↑ → 期限溢价↑ → 长端↑
放任通胀（降息/QE）       → 通胀预期↑ → 期限溢价↑ → 长端↑
```

两条路都指向长端上行——这就是他 2025-11 说「长端利率的 secular decline 已经结束」、2026 年说「最小阻力路径向上」的机制版，也是「higher for longer」在他这里的真正含义：**不是 Fed 不降息，而是降息也压不住长端**。

## 4. 可证伪规则（10–12 条，编号 JG1…；每条：名称 / 触发条件（阈值必须能用本地数据计算）/ 含义 / 资产映射 / 失效条件 / 严重度 info|watch|warn|critical）

**JG1 · 实际利率天花板**
- 触发：`US10Y_REAL ≥ 2.75%`（2015 以来 99 分位）且 `Δ20d(US30Y − US10Y) ≥ +10bp`
- 含义：实际利率进入历史极值区，久期赔率开始有利；但若 JG7 同时触发，则「极值」会被财政主导拉长，不能单独抄底
- 资产映射：5–10Y 国债分批建仓；TIPS 优于名义；黄金待 JG8 确认
- 失效：`US10Y_REAL ≤ 2.40%` 或 `Δ20d(30s10s) ≤ −10bp`（说明是避险买盘而非供给冲击）
- 严重度：watch

**JG2 · 双模型公允区间（两侧）**
- 触发：`US10Y ≤ 4.40%`（混合模型 4.9% 下方 50bp）→ 贵；`US10Y ≥ 6.00%` 或 `US30Y ≥ 6.50%` → 他定义的买点
- 含义：区间内做趋势跟随，区间外才做反转；不把 4.9% 当均值回归目标
- 资产映射：≤4.40% 减久期、不追多；≥6.00% 分批加 5–10Y 久期（30Y 要 6.5%）
- 失效：赤字/GDP 升破 8%，或 `EFFR` 下行同时 `US_FED_DEBT` 60 日增量创 2015 以来新高（隐性 QE）→ 整个区间上移
- 严重度：warn

**JG3 · 熊陡=财政/通胀溢价**
- 触发：`Δ20d(30s10s) ≥ +15bp` 且 `Δ20d(US10Y) ≥ +20bp` 且 `Δ20d(EFFR) ≤ 0`
- 含义：长端主导的陡峭化，是供给与期限溢价，不是增长
- 资产映射：低配/做空 30Y；多 TIPS、黄金、价值股；美元中性偏强
- 失效：`Δ20d(US10Y) ≤ −15bp`（转为避险牛陡），或 `US10Y_BE ≤ 2.0%`（通胀预期配合下行=需求冲击）
- 严重度：warn

**JG4 · 牛陡=衰退定价**
- 触发：`Δ20d(2s10s) ≥ +20bp` 且（`Δ20d(EFFR) < 0` 或 `Δ20d(US2Y) ≤ −25bp`）
- 含义：短端崩、降息定价，衰退概率上升（他 2025-08 用的正是 2Y 领先）
- 资产映射：加 5Y 久期；减 HY/私募信贷代理、周期股；多黄金
- 失效：`US10Y_BE ≥ 2.60%`（陡峭化其实是熊陡的伪装），或 `US2Y − EFFR ≥ 0` 重新转正
- 严重度：warn

**JG5 · 去倒挂倒计时**
- 触发：`2s10s` 从 `≤ −10bp` 转正并维持 20 个交易日
- 含义：他 2024-01 的判断工具——去倒挂后 6–18 个月进入衰退
- 资产映射：全面防御；加中段久期、减高收益、股票降杠杆
- 失效：同期 `Δ20d(US10Y_REAL) ≥ +30bp`（这是熊陡式去倒挂，不是衰退式）→ 降级为 info
- 严重度：critical

**JG6 · 反应函数缺口**
- 触发：`US2Y − EFFR ≥ +50bp` 持续 10 个交易日 → 加息在途；`≤ −70bp` → 降息在即
- 含义：美联储跟随 2Y，不引领 2Y；这条规则在 2025（−70bp 后三次降息）与 2026（+92bp 后 9 月加息）都被验证
- 资产映射：+50bp 以上不做多久期、美元偏强、黄金等回撤；−70bp 以下加久期与黄金
- 失效：FOMC 声明明确排除某一方向（文本证据），或缺口由 2Y 单独跳动造成而 `US10Y` 20 日变化 < 5bp
- 严重度：warn

**JG7 · 财政主导（水床）**
- 触发：`赤字TTM/GDP ≥ 6%` 且 `利息TTM/收入TTM ≥ 20%`
- 含义：财政约束进入反应函数，长端与实际利率有结构性上行压力，美元结构性偏空
- 资产映射：低配长端、多实物资产与黄金、EM 本币债；股债同向风险上升
- 失效：赤字/GDP 回落至 4% 以下，或利息/收入 < 15%（连续两个季度）
- 严重度：watch

**JG8 · 黄金-实际利率脱钩**
- 触发：`corr60(US10Y_REAL, XAUUSD) ≥ +0.20` 且 `GOLD_MOM_20D_PCT ≥ +5%`
- 含义：黄金定价切到货币/储备属性（他 2025-09 给 25% 配置的机制）
- 资产映射：黄金超配；黄金股作为杠杆表达；减美元现金
- 失效：corr 回到 ≤ −0.50（重新由实际利率主导）
- 严重度：watch

**JG9 · 黄金追高禁入**
- 触发：`GOLD_MOM_20D_PCT ≥ +15%` 且 `XAUUSD 距 60 日高点回撤 ≥ 8%`
- 含义：他 2026-04-29 的做法——「跌破 4,000 才是更便宜的入场点」，不追垂直拉升
- 资产映射：黄金减仓/等回撤；不新增黄金股
- 失效：`CB_GOLD_GLOBAL_TONNES` 20 日增量 > 2015 以来 90 分位（央行买盘压过技术回撤）
- 严重度：info

**JG10 · 股债同向（60/40 失效）**
- 触发：`corr60(SPX 日收益, ΔUS10Y) ≥ +0.20`
- 含义：债券不再对冲股票，60/40 是「hollow trees」
- 资产映射：杠铃（短久期高质量债+长久期只在 JG2 买点）+ 实物资产 20% + 等权股票 + EM 本币债
- 失效：corr ≤ −0.20 持续 20 日（回到 2000–2020  regime）
- 严重度：warn

**JG11 · 信用裂缝代理**
- 触发：`SPX 20 日跌幅 ≥ 8%` 且 `HG/GC 20 日跌幅 ≥ 6%` 且 `NDX/SPX 60 日比值跌幅 ≥ 5%`
- 含义：无 HY OAS 时的最佳代理——股票、铜金比、AI 集中度三处同时恶化，对应他说的「CCC 与 AI 利差先裂」
- 资产映射：减信用债/私募信贷代理、加国债与黄金；股票转等权
- 失效：SPX 收复 20 日跌幅一半以上，或（若未来接入）HY OAS 未同步走阔
- 严重度：warn

**JG12 · 美元结构性空头：确认与止损**
- 触发（确认）：`Δ60d(DXY) ≤ −4%` 且 `corr60(DXY, US10Y) ≤ 0`；触发（止损）：`Δ60d(DXY) ≥ +5%`
- 含义：他的核心主题是「美元 secularly weak，即使衰退也弱」；但结构性叙事必须让位于动量止损——2026 年 DXY 从 96.35 反弹到 103.9 就是反例
- 资产映射：确认时加 EM 本币债、黄金、非美股票；止损时把美元空头降为 info，等再确认
- 失效：`Δ60d(DXY) ≥ +5%` 且维持 20 日（当前 +4.8%，已接近触发）
- 严重度：watch

## 7. 与美联储透镜、宋鸿兵透镜的差异与互补（明确指出哪些情形会给出相反信号）

| 维度 | 美联储透镜 | 宋鸿兵透镜 | 冈拉克透镜 |
|---|---|---|---|
| 时间尺度 | 3–18 个月 | 3–10 年 | 6 个月–3 年（结构判断可到 5 年） |
| 核心变量 | Fed 反应函数、声明文本、FCI | 美元环流、秩序溢价、央行购金 | 期限溢价、供给、信用周期 |
| 对 Fed 的看法 | Fed 是自变量 | Fed 是美元体系的执行者 | **Fed 是因变量，2Y 才是自变量** |
| 对长端 | 降息→收益率下行 | 秩序重构→长端中枢上移 | 降息也可能长端上行（水床） |
| 对美元 | 中性（数据驱动） | 潮汐回流→危机时美元强 | 结构性弱，衰退时也弱 |
| 对黄金 | 实际利率与实际政策利率 | 央行购金与去美元化 | 货币属性+美元弱+实际利率脱钩 |
| 失灵场景 | 财政主导、供给冲击 | 短周期流动性危机 | 战术时点、美元反弹 |

**会给出相反信号的四种情形：**

1. **Fed 降息 vs 长端方向。** 美联储透镜读到降息→久期与黄金多；冈拉克透镜在 JG7 触发时读到「降息也压不住长端」→ 久期空/低配。2025-12 至 2026-10 正是此情形（EFFR 3.64→3.88，10Y 4.13→5.31），两镜方向相反，冈拉克对。
2. **衰退时的美元。** 宋鸿兵透镜的「美元微笑」认为危机时美元回流走强；冈拉克认为衰退+赤字货币化时美元跌 20%+。2026 年 DXY +7.9% 暂时站在宋镜一边，但两者对「下一轮衰退」的美元方向完全相反，必须用 `Δ60d(DXY)` 与 `corr60(DXY, US10Y)` 现场裁决，而不是选边站。
3. **黄金的买点。** 宋镜用央行购金/COMEX 库存给出「长期多」；冈拉克用实际利率与追高规则（JG9）给「短期不追」。2026-01 至 2026-11 黄金 −31%，冈拉克短周期对、宋镜长周期未必错——两镜叠加的正确用法是「宋镜定方向、冈镜定买点」。
4. **对中国/EM 的读法。** 宋镜把中国视为秩序替代者（制度叙事）；冈拉克几乎不谈中国制度，只看弱美元→EM 本币债与股票。当美元走强时，宋镜读「潮汐收割」（利好美元资产），冈拉克读「空头止损但结构未变」——对 EM 的仓位建议会相反。

**互补之处：** 三镜共享同一套日频面板，冈拉克镜补上了前两镜最缺的两块——**期限溢价的定价机制**（Fed 镜只看政策利率，宋镜只看秩序）与**信用周期的可交易时点**（宋镜只有长周期叙事）。合成时建议：宋镜给方向权重、冈镜给赔率与买点、Fed 镜给短期政策路径，三者一致时提高置信度，分歧时以「可编程规则是否触发」为准。
