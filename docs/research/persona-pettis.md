## 1. 结论（8 条）

1. **贸易差额是「残差」，不是「竞争力」**：经常账户余额恒等于国内储蓄减投资（S−I），汇率与产业政策决定贸易的*构成*而非*总量*；因此「靠谈判让中国多买美国货」不改变美国逆差总量，只改变逆差来源国——交易含义：不要把双边贸易协议当美元/美债的方向性信号。
2. **顺差国的顺差是「被迫」的**：中国、德国、日本、韩国等高储蓄经济体若不输出顺差，就必须压缩生产、裁员（佩蒂斯 2025-04-23 原话）；顺差是维持就业的政治必需品，而不是可以自愿放弃的竞争优势——交易含义：顺差收缩只能通过「减产」或「扩内需」两条路，前者利空全球周期股与工业金属。
3. **美国只有「失业」或「债务」两条路**：作为储备货币发行国，美国被动容纳他国过剩储蓄；调整不落在失业上，就落在债务与资产价格上（佩蒂斯 2023-06-29、2026-08-28 一以贯之）——交易含义：美国财政赤字率与实际利率的组合，比美联储措辞更能解释黄金与长端美债。
4. **全球实际利率是储蓄过剩的价格，而非货币政策的价格**：顺差国储蓄输出压低了安全资产实际收益率；一旦再平衡（顺差国消费上升/储蓄下降）或逆差国限制容纳（关税、资本管制），实际利率中枢上移、期限溢价走阔——交易含义：这是「做空长端美债 + 做多黄金」这一组合唯一的基本面来源，也是它唯一会被推翻的地方。
5. **中国的问题是储蓄过剩，不是产能过剩，也不是「资产负债表衰退」**：家庭收入占 GDP 比重过低→消费占比过低→投资必须高→投资回报递减→债务/GDP 上升是会计恒等式的结果；债务飙升是征兆，真正的问题是过去十年投资配置不当的**未确认损失**（2023-12-22、2024-04-30，E1 标题+编者按）——交易含义：以「去产能/反内卷」为核心的政策包，不改变失衡，只改变价格。
6. **人民币贬值不提振中国增长**：贬值降低家庭实际购买力、进一步压低消费占比、加重失衡，无法增加投资（2022-04-28，E1）——交易含义：USDCNH 快速贬值而 A 股/中国利率不涨，是「贬值无效」的现场确认，应视为中国风险溢价上升而非出口利好。
7. **中国几乎必然选择「把调整摊到很多年」**：维持最大顺差、让外部吸收过剩产出，是政治上最优、经济上次优的路径（2026-08-28，E2 转述）——交易含义：在没有外部强制或内部危机前，不要押注快速再平衡；「再平衡交易」（多消费股/空投资链）应等政策信号而非估值信号。
8. **再平衡的成本由权力分配，而不是由经济学分配**：逆差国政治弱、无法独立融资/捍卫汇率/管制资本时承担成本；顺差国在逆差国足够强大、能限制进口与资本流入时承担风险（2026-08-28，E2）——交易含义：2026 年后的核心变量是「美国是否真的限制容纳」，而这是政治变量，须用关税/资本管制新闻而非宏观数据触发。

## 2. 框架与世界观

### 2.1 储蓄-投资恒等式：一切的起点

- 开放经济恒等式：**S − I = CA**（国民储蓄 − 国内投资 = 经常账户余额）。
- 推论一：经常账户是**结果**，不是目标。想改变 CA，必须改变 S 或 I；只改变关税、汇率、双边采购，CA 总量不动。
- 推论二：**「储蓄过剩」是结构性的**，来自收入分配（家庭部门在国民收入中的份额）而非消费者偏好。佩蒂斯反复用「hidden transfers from the household sector」描述中国模式：低估的汇率、低于生产率的工资增长、**最重要的：被压低的利率**（2013-03 访谈，E2）。
- 推论三：储蓄过剩的输出形式是资本输出。顺差国买外国资产，等于把本国储蓄借给外国消费者/政府去吸收本国产能；这就是「全球失衡」的金融面。

### 2.2 经常账户与资本账户的镜像

- 恒等式：**CA + KA + ΔReserves = 0**（忽略误差与遗漏）。中国顺差 = 储备积累 + 对外投资 + 隐性资本外流；美国逆差 = 资本净流入 = 外国人持有美国资产增加。
- 佩蒂斯的关键倒装：**不是「中国储蓄多所以美国逆差」，而是「美国愿意容纳，所以中国可以继续储蓄多」**。美元资产需求（储备货币特权）使美国成为「最后消费者/最后借款人」；美国的贸易政策因此只有两条路：迫使顺差国改变储蓄-投资结构，或限制美国自己的容纳角色（关税、资本管制、削弱美元的国际角色）。2025-04-20 原话：「American trade policy must either reverse the savings imbalance in the rest of the world, or it must limit Washington's role in accommodating it.」「Bilateral tariffs do neither.」（E2 转述，逐字引语来自二手引述）
- 「特里芬式约束」的佩蒂斯版本：储备货币国必须持续输出安全资产→必须逆差→国内必须在「失业上升」或「债务/资产价格上升」之间选一个。美国 2008 年前选资产泡沫、2010 年代选财政赤字与 QE、2020 年代选财政扩张，本质是同一条约束的不同解法。

### 2.3 中国增长模式的会计约束

设 GDP = C + I + G + NX。给定增长目标 g，若 C/GDP 被压在 ~38%（家庭消费占比极低），则 I/GDP 必须高到 ~40%+ 才能维持 g。
- **回报递减**：投资回报率随投资占比上升而下降 → 单位新增 GDP 需要的信贷增量上升（增量资本产出率 ICOR 上升）。
- **债务是算术结果**：当投资回报 < 融资成本时，缺口只能由新增债务和未确认损失吸收；账面债务/GDP 上升是必然，不是政策失误。
- **佩蒂斯的诊断句**：「债务飙升本身不是问题，而是问题的征兆；真正的问题是过去 10 年里未被确认的与投资配置不当相关的损失。」（2023-12-22，E1 标题+编者按）
- **再平衡的硬约束**：提高家庭收入份额 = 提高工资 = 削弱制造业国际竞争力（2026-11 转述，E3）。这是中国再平衡比日本更难的额外一层约束。

### 2.4 再平衡的三种（实为四种）路径

| 路径 | 机制 | 谁承担成本 | 市场含义 |
|---|---|---|---|
| **A. 顺差国扩内需** | 收入再分配→家庭消费↑→储蓄↓→顺差自然缩小 | 顺差国资本/出口部门 | 顺差国货币升值、消费股重估、全球实际利率上移 |
| **B. 顺差国压缩生产** | 顺差被迫收缩→减产裁员 | 顺差国劳动者 | 全球通缩、工业金属崩、避险资产强 |
| **C. 逆差国限制容纳** | 关税/资本管制/产业政策→减少吸收外国储蓄 | 逆差国消费者（短期）、顺差国出口部门 | 美元弱、美国通胀黏性、黄金强 |
| **D. 债务维持现状（佩蒂斯认为中国实际在走）** | 继续高投资、以债务吸收未确认损失 | 顺差国纳税人/储户（未来） | 中国利率下行、人民币缓贬、A 股区间震荡、商品结构性分化 |

佩蒂斯的判断：**A 政治上最难（要动分配），B 经济上最痛（要动就业），C 取决于美国权力意志，D 只是推迟**。所以基准情形是「D 为主 + C 间歇性升级 + A 缓慢且不彻底」。

### 2.5 储蓄过剩如何压低全球利率：机制链条

佩蒂斯对「全球利率中枢」的解释不是货币政策，而是一条会计链条：

1. **顺差国的储蓄必须被安置**：中国、德国、日本、韩国的过剩储蓄以资本输出形式流入美国（买美债、买美股、买地产、直接投厂）。
2. **资本流入国被迫「容纳」**：美国要么用这些钱支撑国内消费与资产价格（家庭债务/财政赤字上升），要么面临需求不足与失业上升。容纳的过程就是**美国储蓄率下降、投资/消费超过本国储蓄**。
3. **安全资产需求被放大**：顺差国买的是「安全、可抵押、流动性最好」的资产，即美债与美元资产；这压低**长端实际利率与期限溢价**，而不是短端政策利率。
4. **所以全球实际利率的中枢由「储蓄供给」决定**：只要顺差国继续输出储蓄，实际利率就会低于「美国国内储蓄-投资」均衡应有的水平；美联储决定的是围绕这条结构性水平的周期波动。
5. **什么会终结它**：顺差国再平衡（A、储蓄供给↓）→ 实际利率中枢上移；逆差国限制容纳（C、资本流入↓）→ 同样上移；顺差国压缩生产（B）→ 短期通缩压低利率，但随后以政策宽松/货币化收场；债务维持（D）→ 利率长期低位、但期限溢价因财政供给而走阔（即曲线陡峭化、长端不跌）。

**这个链条的可观测推论**：如果「低实际利率 + 强美元 + 美国赤字率高」三者同时成立，说明储蓄过剩仍在被容纳（MP1）；如果实际利率与期限溢价同时上行而美元走弱，说明再平衡启动（MP2）。两者之间的切换，是本透镜最核心的交易方向。

### 2.6 与主流贸易理论的四个分歧

| 议题 | 主流（比较优势/关税福利分析） | 佩蒂斯 |
|---|---|---|
| 贸易差额的决定因素 | 相对价格、储蓄率、汇率、竞争力共同决定 | 储蓄-投资缺口决定总量；价格/汇率只决定结构 |
| 汇率的作用 | 贬值改善贸易差额 | 贬值不改善总量，只压低顺差国实际收入与消费 |
| 关税福利 | 净损失（消费者剩余损失 > 生产者剩余） | 若关税提高国内生产*且*拉动消费，则可成为再平衡工具；否则由消费者承担、失败 |
| 失衡的责任 | 逆差国过度消费 | 顺差国压制家庭收入（收入分配问题），美国被动容纳 |

分歧的实盘意义：主流框架下「人民币贬值=利好出口链」，佩蒂斯框架下「人民币贬值=中国失衡加剧、增长不受益」（2022-04-28）。两者在 A 股出口链上会给出相反方向（见第 7 节）。

### 3.1 三个合成信号（由上面的指标派生，可直接写入 `config/lens.yaml`）

1. **容纳指数 `ACCOM`** = `z(US10Y_REAL)*(-1) + z(DXY)/2 + 财政赤字率/10`。越高说明美国越多地吸纳全球储蓄。方向：`ACCOM` 高位→黄金与长久期美债多、美元中性偏强；`ACCOM` 快速回落→再平衡启动。
2. **中国失衡指数 `CN_IMB`** = `pct60(I)/10 + pct60(USDCNH)*2 - chg60(CN10Y)/20 + z(CN_GOLD_PREMIUM_PCT)/2`。越高说明投资+贬值+宽松+居民避险同时存在（D 路径强化）。方向：`CN_IMB` 高位→中国利率债多、工业金属空、A 股区间。
3. **再平衡真实度 `REBAL`** = `chg60(CN10Y2Y)/20 + pct60(000300)/10 + pct60(CU/GC)/10 - z(CN_GOLD_PREMIUM_PCT)`。只有 `REBAL ≥ 3` 才认定为 S3（A 路径）启动；这是本透镜唯一会「翻多中国内需」的条件。

> 三个合成信号都只用本地序列，可在 `backend/app/lens/` 内以 20 行以内代码实现；建议以 `info` 级写入合成输入，作为规则 MP1–MP12 的上下文而非独立触发器。

## 4. 可证伪规则

> 每条规则的阈值均可在本地数据上计算。严重度：`info` 仅记录 / `watch` 进入观察 / `warn` 触发预警 / `critical` 触发核心仓位调整。
> 约定：`z()` 用 1260 日窗口；`r(s,e)` 表示序列 s 相对序列 e 的 60 日收益率差。

**MP1 储蓄过剩压制实际利率**
- 触发：`z(US10Y_REAL) ≤ -1.0` 且 `z(DXY) ≥ 0.5` 且 `sum(US_MTS_DEFICIT,12M)/WB_US_GDP ≥ 5%`
- 含义：全球储蓄仍在被美国吸纳，实际利率被压低而美元维持强势——「失衡未调整」的典型组合。
- 资产映射：多黄金（`XAUUSD`）、多长久期美债、空铜金比；A 股/新兴市场以区间为主。
- 失效条件：`US10Y_REAL` 上行突破 1.5% 且 `DXY` 与 `US10Y_REAL` 同向走强（此时是紧缩而非储蓄过剩）。
- 严重度：`watch`

**MP2 再平衡启动：实际利率与期限溢价同向上升**
- 触发：`z(US10Y_REAL) ≥ 1.0` 且 `chg60(US30Y - US10Y) ≥ +15bp` 且 `pct60(DXY) ≤ -2%`
- 含义：顺差国储蓄输出减少或美国限制容纳，全球储蓄供给下降→实际利率与期限溢价上移、美元走弱（佩蒂斯式再平衡）。
- 资产映射：空长端美债、多黄金、多非美货币、多中国消费类资产（若同时满足 MP9）。
- 失效条件：`US30Y-US10Y` 走阔但 `US10Y_REAL` 同步下行（此时是避险/衰退定价，不是再平衡）。
- 严重度：`warn`

**MP3 人民币贬值无效**
- 触发：`pct20(USDCNH) ≥ 2%` 且 `pct20(000300) ≤ 0` 且 `chg60(CN10Y) ≥ -10bp`（即中国利率未因贬值预期而下行）
- 含义：贬值既未带来增长预期改善、也未带来宽松空间，符合佩蒂斯「贬值压低消费、加重失衡」的判断。
- 资产映射：空 A 股/多美元兑人民币的对冲失效；多黄金；对中国利率债中性偏多（基本面弱）。
- 失效条件：`pct20(USDCNH) ≥ 2%` 且 `pct20(000300) ≥ 3%` 且 `CN_GOLD_PREMIUM_PCT` 回落（贬值被市场解读为出口利好且资本外流未恶化）。
- 严重度：`warn`

**MP4 中国内需收缩确认（投资链走弱）**
- 触发：`chg60(CN10Y) ≤ -15bp` 且 `pct60(I) ≤ -5%` 且 `pct60(CU/GC) ≤ -3%`
- 含义：利率下行+铁矿石与铜金比同步走弱=投资驱动模式在收缩，储蓄过剩的基本面确认，政策对冲概率上升。
- 资产映射：多中国利率债、空工业金属、A 股内部从周期切向政策受益方向。
- 失效条件：三项中两项反转（尤其 `pct60(I) ≥ +5%`）。
- 严重度：`warn`

**MP5 美国「债务路径」加深（财政主导）**
- 触发：`sum(US_MTS_DEFICIT,12M)/WB_US_GDP ≥ 6%` 且 `sum(US_MTS_INTEREST,12M)/sum(US_MTS_RECEIPTS,12M) ≥ 20%` 且 `z(US10Y_REAL) ≤ 0.5`（实际利率未相应上行）
- 含义：美国用低实际利率吸收赤字与储蓄，长期不可持续——佩蒂斯「要么失业要么债务」的债务侧极端。
- 资产映射：多黄金（核心）、多通胀挂钩资产、空美元长期（分批）、美债曲线做陡。
- 失效条件：`US10Y_REAL` 上行 ≥ +50bp/60 日且 `US5Y_BE` 回落（债务被真实利率吸收，风险释放）。
- 严重度：`warn`

**MP6 美国的「失业路径」确认**
- 触发：`WB_US_UNEMPLOYMENT` 较上年上升 ≥ 0.5pct 且 `sum(US_MTS_DEFICIT,12M)/WB_US_GDP ≥ 5%`（年频，仅作背景确认）
- 含义：调整成本落到就业而非债务，美国进入再平衡的「痛」阶段；贸易与资本政策会更激进。
- 资产映射：多黄金、多美债久期、空周期股与工业金属；美元先强后弱。
- 失效条件：失业率上升但赤字率同步降至 <4%（财政收缩成功，属 A/C 路径）。
- 严重度：`watch`

**MP7 关税「成功/失败」判据**
- 触发（成功侧）：`sum(US_MTS_DEFICIT,12M)/WB_US_GDP` 较 12 个月前下降 ≥ 1pct 且 `WB_US_UNEMPLOYMENT` 未上升 且 `pct60(SPX) ≥ 0`
- 触发（失败侧）：赤字率未降 ≥ 1pct 且 `pct60(DXY) ≥ +2%` 且 `pct60(SPX) ≤ -3%`
- 含义：佩蒂斯判据——关税只有在提高国内生产并拉动消费时成功（2024-12-11，E1 编者按）；否则由美国消费者承担成本。
- 资产映射：失败侧→多黄金、空美元、空美国周期股；成功侧→多美元、空长端美债（通胀/利率上行）。
- 失效条件：美国贸易差额数据（本工具缺失）出现反向证据；只能以财政赤字+汇率+股指三角代理，误判率较高。
- 严重度：`info`（代理不完美，仅记录）

**MP8 中国「推迟再平衡」路径延续**
- 触发：`chg60(CN10Y) ≤ -20bp` 且 `pct60(USDCNH) ≥ +2%` 且 `pct60(000300) ≥ 0`
- 含义：中国同时使用汇率贬值与货币宽松对冲，且股市在政策预期下上涨——D 路径（债务维持现状）的典型价格组合。
- 资产映射：A 股短期反弹但中期失衡加剧；多中国利率债；多黄金；空铁矿石（投资边际递减）。
- 失效条件：`pct60(000300) ≥ +10%` 伴随 `CN10Y2Y` 走陡且 `CN_GOLD_PREMIUM_PCT` 回落（再平衡/内需改善信号）。
- 严重度：`watch`

**MP9 中国再平衡的真实启动信号**
- 触发：`CN10Y2Y` 走陡 `chg60 ≥ +20bp` 且 `pct60(000300) ≥ +5%` 且 `pct60(CU/GC) ≥ +3%` 且 `CN_GOLD_PREMIUM_PCT` `z ≤ 0`
- 含义：消费/内需改善+期限利差走陡+居民风险偏好回升，是佩蒂斯框架里唯一「健康」的再平衡价格组合（A 路径）。
- 资产映射：多 A 股（消费/内需）、多人民币、空中国利率债、多大宗（消费型：油、农产品）。
- 失效条件：股市上涨但期限利差走平、黄金溢价扩大（仅流动性行情，非再平衡）。
- 严重度：`warn`

**MP10 资本外流/管制强化信号**
- 触发：`z(CN_GOLD_PREMIUM_PCT) ≥ 1.5` 且 `chg90(CN_GOLD_RESERVES_USD) ≥ 2%` 且 `pct60(USDCNH) ≥ +1.5%`
- 含义：居民溢价+官方增持黄金+汇率贬值同时出现，说明顺差国对「容纳」的不信任上升、资本管制压力加大。
- 资产映射：多黄金（核心）、多离岸美元、空 A 股外资敏感板块。
- 失效条件：`CN_GOLD_PREMIUM_PCT` 回落且 `pct60(USDCNH) ≤ 0`。
- 严重度：`warn`

**MP11 全球失衡的「美国独自再平衡」压力**
- 触发：`chg60(DE10Y - US10Y) ≥ +20bp` 且 `pct60(EURUSD) ≥ +2%` 且 `z(US10Y_REAL) ≥ 0.5`
- 含义：资本回流欧洲+美元走弱+实际利率上行，欧洲被迫承接部分调整成本（2026-08-28 佩蒂斯判断，E2）。
- 资产映射：多欧元、多欧洲久期、多黄金；空美元。
- 失效条件：德美利差走阔但欧元未升值（避险资金仍去美元）。
- 严重度：`info`

**MP12 黄金作为「失衡税」**
- 触发：`z(GOLD_PRICE_USD) ≥ 1.5` 且 `pct252(GOLD_PRICE_USD) ≥ 15%` 且 `z(US10Y_REAL) ≤ 0`
- 含义：黄金在实际利率不低的环境里上涨，说明定价的是对法币/失衡的信任折价，而非利率——佩蒂斯框架下最一致的黄金多头环境。
- 资产映射：多黄金、多白银（`SI`）、多金矿股（本地无，用 `AU` 代理）。
- 失效条件：黄金上涨同时 `US10Y_REAL` 上行 ≥ +50bp（实际利率驱动的空头，属反向）。
- 严重度：`watch`

### 4.1 规则组合与优先级

- **结构性背景（常开）**：MP1（储蓄过剩）或 MP5（财政主导）至少一条成立 → 全局基调「再平衡未发生」，黄金底仓不下调。
- **切换触发（最重要）**：MP2（再平衡启动）与 MP9（中国再平衡真实启动）同时成立 → 从「多黄金/空长债/空内需」切换到「多内需/多顺差国货币/空中国利率债」，这是唯一允许反向操作的组合。
- **风险触发（降仓）**：MP3（贬值无效）或 MP8（推迟再平衡）触发且 `pct20(000300) ≤ -5%` → 中国风险资产减仓，黄金加仓。
- **事件触发（人工）**：MP7 与新闻 RSS 的关税/管制事件同日出现 → 由人工复核后再动作，不自动下单。
- **互斥处理**：MP1 与 MP2 不可能同时成立（实际利率 z 值方向相反），若出现，说明数据窗口在切换期，以 20 日均值重算并降级为 `info`。

## 5. 资产映射表

> 情景定义：**S1 推迟（D 路径主导）**：中国继续投资+顺差，外部压力间歇；**S2 外部强制（C 路径）**：美国限制容纳，关税/资本管制升级；**S3 内部再平衡（A 路径）**：家庭收入份额上升、消费接力；**S4 危机式调整（B 路径）**：债务破裂、汇率重估、生产压缩。

| 资产 | S1 推迟（基准） | S2 外部强制 | S3 内部再平衡 | S4 危机调整 |
|---|---|---|---|---|
| **A 股** | 区间震荡，政策脉冲驱动；周期与出口链占优，消费偏弱 | 先跌后分化：出口链承压、内需政策受益股相对占优 | 系统性重估：消费/服务/内需龙头 ROE 抬升，长期牛市起点 | 无序下跌，外资流出，流动性风险优先 |
| **人民币** | 缓贬（政策容忍），波动率低 | 贬值压力加大但被管制对冲；离岸价差走阔 | 升值（实际收入上升+资本回流） | 急贬后重估，或资本管制+汇率双轨 |
| **中国利率** | 下行/低位（储蓄过剩+宽松），曲线平坦 | 短端受稳汇率约束，长端下行（衰退预期） | 中枢上移，曲线陡峭化（消费+通胀预期） | 先急升（信用风险）后货币化，实际利率为负 |
| **大宗商品** | 分化：铁矿/铜受投资托底但边际递减；油受全球需求拖累 | 中国投资对冲加码→黑色系短期强；全球需求弱→油弱 | 消费型商品（油、农产品）强，投资型（铁矿、铜）相对弱 | 全面下跌（需求崩塌），黄金除外 |
| **美债** | 短端下行、长端震荡（储蓄过剩压收益率，但财政供给/期限溢价压制） | 收益率上行（关税通胀+资本回流美国减少），曲线陡 | 实际利率上行，长端承压（全球储蓄供给下降） | 避险先涨，随后因通胀/财政货币化而跌 |
| **美元** | 强（容纳角色延续），但长期信用折价缓慢积累 | 短期强（避险）后转弱（政策不确定性/资本管制反噬） | 弱（顺差国不再输出储蓄） | 初期急强（美元荒），后期弱（体系重构） |

**关键交叉判断**：
- **S1 与 S2 的中国利率方向相反吗？** 不相反，都偏下行——但驱动不同（S1 是储蓄过剩，S2 是衰退）。**S1 与 S3 才是方向相反的一对**，这是本透镜最有交易价值的切换点。
- **黄金在四个情景里只有 S3 可能承压**（实际利率上移），S1/S2/S4 都偏多；这与宋鸿兵透镜「结构性永远多」不同，是本透镜相对更可证伪的地方。

### 5.1 情景判定清单（只用本地指标，供每日收盘后自动打分）

| 情景 | 必要条件（本地可算） | 否决条件 |
|---|---|---|
| **S1 推迟** | `sum(US_MTS_DEFICIT,12M)/WB_US_GDP ≥ 5%` 且 `pct60(USDCNH) ≥ 0` 且 `chg60(CN10Y) ≤ 0` 且 `pct60(I) ≥ -5%` | `CN10Y2Y` 走陡 ≥ +20bp 且 `000300` 60 日涨幅 ≥ +5%（转向 S3） |
| **S2 外部强制** | 新闻 RSS 出现关税/出口管制/资本管制事件 且 `pct60(DXY) ≥ +2%` 且 `pct60(I) ≤ -5%` | 关税事件后 `sum(US_MTS_DEFICIT,12M)/WB_US_GDP` 未下降且 `pct60(SPX) ≤ -3%`（转向「关税失败」） |
| **S3 内部再平衡** | `chg60(CN10Y2Y) ≥ +20bp` 且 `pct60(000300) ≥ +5%` 且 `pct60(CU/GC) ≥ +3%` 且 `z(CN_GOLD_PREMIUM_PCT) ≤ 0` | `CN10Y` 仍下行 ≥ 15bp（宽松而非再通胀） |
| **S4 危机调整** | `pct20(USDCNH) ≥ 4%` 且 `pct20(000300) ≤ -8%` 且 `chg60(CN10Y) ≤ -30bp` | 央行干预后汇率与股指同步回稳（退化回 S1） |

打分建议：每个情景 0–1 分，按 `0.4×必要条件满足比例 + 0.6×否决条件未触发比例` 加权，取最高分作为当期主情景；主情景与持仓情景不一致时，只允许减仓、不允许加仓（防止在结构约束上逆势加杠杆）。

**时点偏差的量化观察**：佩蒂斯的「大再平衡」叙事从 2013 年《The Great Rebalancing》延续到 2026-08-28 的 FA 文章，跨 13 年；期间发生过多次「看似要再平衡」的假启动（2015–2016 供给侧改革、2020 双循环、2024「以旧换新」消费刺激），每次都以「投资/出口再度托底」收场。这提示本透镜的规则应设**较长的确认窗口**（≥60 交易日）与**较低的严重度上限**（除 MP5/MP10 外不超过 `warn`）。

**总体评估**：佩蒂斯在**方向与结构**上命中率高（顺差扩大、债务是征兆、贬值无效、关税不解决总量），在**时点**上系统性偏早（他从 2013 年就在预言大再平衡，见 SCMP 2026-08-31 的批评，E2）。这决定了本透镜的使用方式：**做中期约束与情景权重，不做择时**。

## 7. 与美联储透镜、宋鸿兵透镜的差异与互补

| 维度 | 美联储透镜 | 宋鸿兵透镜 | 佩蒂斯透镜 |
|---|---|---|---|
| 核心问题 | 政策反应函数：加息/降息的条件 | 货币体系与黄金：美元霸权何时裂 | 谁在储蓄、谁在投资、谁承担调整成本 |
| 自变量 | 通胀、就业、金融条件 | 美元信用、地缘、央行购金 | 储蓄-投资缺口、收入分配、财政/贸易结构 |
| 时间尺度 | 周–季度 | 年–十年 | 季度–数年（结构约束） |
| 对黄金 | 实际利率驱动，方向可正可负 | 结构性超配（体系崩塌对冲） | 储蓄过剩+财政主导时多；再平衡成功时承压 |
| 对美元 | 利差与避险决定 | 长期衰落 | 短期由「容纳」支撑、长期由失衡不可持续压制 |
| 典型误用 | 把政策路径当结构判断 | 把长期叙事当短期信号 | 把结构约束当择时工具（最危险） |

### 7.1 明确会给出**相反信号**的情形

1. **美联储加息 + 美国赤字扩张**：美联储透镜读作「紧缩→空黄金、多美元」；佩蒂斯透镜读作「债务路径加深→多黄金、空长端美债」。两者相反，胜负取决于实际利率与期限溢价谁主导。
2. **人民币贬值**：宋鸿兵透镜倾向读作「货币战→黄金多、美元信用受损」；佩蒂斯读作「中国失衡加剧、消费受损、对增长无效」（2022-04-28）。方向上都利多黄金，但**对 A 股与中国增长的判断相反**。
3. **中国顺差创新高**：宋鸿兵读作「东升西降/制造业实力」；佩蒂斯读作「失衡恶化、未来调整更痛、不可持续」。这是两镜最根本的对立。
4. **美国贸易逆差收窄**：美联储透镜（若伴随增长强）读作利多美元；佩蒂斯读作「再平衡启动→全球储蓄供给下降→实际利率上行、美元长期转弱」。短期美元方向相反。
5. **美债**：宋鸿兵读作「庞氏、看空」；佩蒂斯读作「储蓄过剩的价格，可能长期低位，直到再平衡」。**在 S1 情景下两者对立**。

### 7.2 互补方式

- **美联储透镜定短端与流动性**（实际利率的分子），**佩蒂斯定长端与期限溢价**（储蓄供给的分母）。二者合成「实际利率 + 期限溢价」的二维框架，正是本工具 `US10Y_REAL`、`US30Y-US10Y` 两条序列的用途。
- **宋鸿兵定黄金的结构性底仓**，**佩蒂斯定黄金的战术加减**：在 S1/S2 加，在 S3 减。
- **冲突处理协议**：当三镜给出相反方向时，按时间尺度排序——周–季度听美联储，季度–数年听佩蒂斯，数年以上听宋鸿兵；并强制在预警信息中标注「本信号来自哪一镜、哪一情景」。

### 9.2 数据缺口（佩蒂斯框架的核心依赖，本工具缺失）

佩蒂斯框架的**两个核心变量——经常账户与家庭消费/储蓄占比——本工具都没有**，这是本透镜最大的结构性弱点。逐项列出与替代方案：

| 缺口 | 为什么关键 | 本地替代代理 | 替代的局限 |
|---|---|---|---|
| **经常账户 / 贸易差额（中、美、德、日）** | S−I=CA 是整个框架的起点，无法直接观测 | 美国用 `sum(US_MTS_DEFICIT,12M)/WB_US_GDP`（财政赤字率）+ `DXY` + `US10Y_REAL` 三角代理；中国用顺差不可得，只能靠 `USDCNH`+`CN_GOLD_PREMIUM_PCT`+`CN_GOLD_RESERVES_USD` 间接推断 | 财政赤字 ≠ 贸易逆差（除非 S−I 结构不变）；中国侧几乎只能定性 |
| **家庭消费占 GDP / 家庭收入份额（中国）** | 佩蒂斯诊断中国失衡的第一性变量 | 无可用代理；只能用 `WB_CN_CPI`（年频通缩）+ `CN10Y` 下行 + `I`/`CU` 走弱推断「内需不足」 | 无法区分「消费弱」与「投资崩」，也无法量化再平衡进展 |
| **投资占 GDP（中国）** | 会计约束的另一半：投资必须高才能维持增长 | `pct60(I)`（铁矿石）、`pct60(CU)`、`CU/GC` | 商品价格受全球供需与供给扰动影响，噪声大 |
| **信贷/社融/债务脉冲（中国）** | 「债务是征兆」需要债务流量验证 | `CN2Y`/`CN10Y` 曲线、`CN10Y2Y` | 利率不等于信贷量；无法测「债务/GDP」 |
| **季度债务/GDP（中国、美国）** | 美国有 `WB_US_DEBT_GDP`（年度），中国完全没有 | 美国用 `US_FED_DEBT/WB_US_GDP`（日频/年度混合）；中国无 | 中国债务风险无法量化，只能定性 |
| **IMF COFER / 储备货币份额** | 验证「美元主导短期不会终结」 | `CN_GOLD_RESERVES_USD`、`CB_GOLD_GLOBAL_TONNES` | 只能看黄金替代，看不到美元份额 |
| **CIPS/人民币跨境结算** | 验证人民币国际化与资本账户 | 无 | 完全缺失 |

### 9.3 学理分歧（不影响使用，但影响置信度）

1. **「储蓄过剩」vs「全球储蓄过剩」的因果方向**：Bernanke 认为全球储蓄过剩是外生的（东亚储蓄↑→美国利率↓）；佩蒂斯认为关键是**收入分配**（顺差国压低家庭收入份额→储蓄↑），因此再分配是唯一解。二者对政策含义不同：前者容忍美国逆差，后者要求顺差国改分配。
2. **关税是否可能成功**：佩蒂斯的判据是「提高国内生产且拉动消费」，但主流贸易经济学认为关税的福利损失大于再平衡收益（AXA IM 2025-01-19 的批评，E2）。本笔记采用佩蒂斯判据作为**可观测规则**（MP7），但把严重度压到 `info`。
3. **「大再平衡」的时点**：佩蒂斯从 2013 年起持续预言，SCMP（2026-08-31）批评其叙事多年未实现。本笔记的处理是：**把「再平衡」当成情景权重而不是日期预测**，这正是第 5 节四情景表存在的原因。
