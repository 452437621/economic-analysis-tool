### 2.2 发现并修复的缺陷（7 项）

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| 1 | **简报时间显示偏移 8 小时**：SQLite 返回的 UTC 裸时间被 `astimezone()` 当作本地时间 | 盘后/外盘标的时间戳错误，可能误判"当日/次日" | 新增 `local_time()` 统一按 UTC 归一后再转本地；补单测 |
| 2 | **任务审计永久挂起**：进程重启后 `job_runs` 停留在 `running` | 面板显示任务"仍在执行"，无法判断真实状态 | 启动时 + 每次任务前 `reconcile_stale_runs()` 改写为 `interrupted`；实测清理 12 条 |
| 3 | **任务开关失真**：调度器忽略 `Job.enabled` | 面板显示"停用"但仍在跑，运维判断失效 | 调度前校验开关；`seed_jobs` 覆盖全部 23 个任务；一次性迁移启用历史误禁的 4 个任务 |
| 4 | **浅层迁移提前 return**：`watchlist.sort_order` 存在时后续迁移被跳过 | 未来迁移静默失效 | 重构为 `app_migrations` 表驱动的独立迁移，可重复执行 |
| 5 | **备份无限增长** | 长期运行占满磁盘 | 保留策略（默认 14 份，`--keep`） |
| 6 | **时区不一致**：证据导出时间、ECB/JGB/东财起始年份用本地时间 | 跨年/跨时区时日期偏差 | 统一 UTC |
| 7 | **8 处真实未使用导入** | 噪声与潜在循环依赖 | 清理并通过 lint 门禁 |

### 2.3 扫描确认无问题的方面

- SQL 注入：全部走 SQLAlchemy 参数化；`text()` 仅用于 PRAGMA 与常量迁移。
- 前端 XSS：所有插值经 `esc()`；简报/证据渲染先转义再格式化。
- 未定义前端引用：`$()` 引用、内联 handler、重复 id **0 处**。
- 写接口错误语义：非法/未知资源返回 4xx，**无 5xx**。
- 资源泄漏：HTTP 客户端、DB 会话均使用上下文管理器。
- API 遗漏：44 个 GET 全部 2xx。

## 3. DevOps 流程（已补全）

```
开发 → 提交
   │
   ├─ scripts\lint.py        静态门禁：语法/AST/导入/编码/前端接线/JS/文档链接/版本
   ├─ pytest                 104 条：单元 + 解析 + API 冒烟 + 降级 + DevOps
   ├─ scripts\ci.ps1         本地单一门禁（lint → test → 运行时）
   └─ .github/workflows/ci.yml  CI：Py3.11/3.12 矩阵 + 安装导入冒烟
          │
          ▼
   发布：CHANGELOG + 版本单一来源 + docs/10 验收矩阵
          │
          ▼
   运行：APScheduler 23 个任务 · 数据质检 · 告警中心 · JobRun 审计
          │
          ▼
   运维：scripts\backup.ps1（完整性 + 保留 14 份）
         scripts\restore.ps1（校验 + DryRun + 安全副本）
         docs/12 异常恢复演练（降级场景与 RTO/RPO）
```

### 3.1 日常命令

```powershell
# 全量门禁（推荐在每次提交前）
powershell -ExecutionPolicy Bypass -File .\scripts\ci.ps1

# 仅静态检查 / 仅测试
.\.venv\Scripts\python.exe scripts\lint.py
.\.venv\Scripts\python.exe -m pytest -q

# 备份（保留 14 份）/ 恢复演练
powershell -ExecutionPolicy Bypass -File .\scripts\backup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\restore.ps1 -DryRun
```

## 5. 残余风险

1. **单一免费数据源依赖**：新浪/东财若改版需适配；已用 SourceHealth + 覆盖质检暴露问题，但无法自动修复。
2. **SQLite 单写者**：多任务并发时依赖 WAL + 重试；个人单用户场景可接受，不适合多用户。
3. **启发式规则**：事件方向、持仓背离、历史类比均为规则/统计推断，需人工复核（界面已标注）。
4. **无自动交易**：V1 明确不下单，计划为草稿。
5. **前端无构建链**：单文件 HTML/JS，便于维护但缺少类型检查；已用 `node --check` + 静态接线检查兜底。
