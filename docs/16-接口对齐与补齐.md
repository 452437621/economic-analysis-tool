> 日期：2026-11-14 · 版本：V1.2.0 · 关联：[15 前端改造方案](15-前端改造方案.md)、[02 系统架构 §11](02-系统架构设计.md)、[07 开发进度](07-开发进度.md)
>
> 黄金监控指标（V1.3）的接口与评分见 [17 黄金监控与综合研判](17-黄金监控与综合研判.md)。

## 0. 结论

对 Vue 前端（8 个页面 + 5 个全局浮层）逐项核对后端接口，共发现 **7 类缺口**，已全部补齐并完成联调：

| # | 缺口 | 处置 |
|---|---|---|
| 1 | 总览页首屏需 20+ 次请求（快照/自选/宏观/简报/任务/日历/告警 + 每标的日线 + 每序列走势） | 新增聚合接口 `GET /api/overview`（一次返回全部，自选含 sparkline） |
| 2 | 行情无显示单位，前端硬编码单位表；会员持仓品种靠前端推导 | 单位落库 `instruments.extra.unit`，快照/自选返回 `unit`；新增 `GET /api/positions/products` |
| 3 | 简报无「日报」分组、无历史期次，无法实现上一期/下一期 | `/api/briefs/latest?kind=daily` 聚合 + `neighbors`；`/api/briefs` 历史分页；新增 `/api/briefs/kinds` |
| 4 | 事件与原文/证据无关联，事件 tab 不可点击 | `/api/events` 返回 `document_id`/`document_ids`/`impact`，并支持 `q`/`instrument`/`offset` |
| 5 | 新闻只有 `limit`，无搜索/来源/等级筛选 | `/api/news` 增加 `q`/`source`/`tier`/`since_days`/`offset` 与 `meta.total` |
| 6 | 日历无筛选、无总数 | `/api/calendar` 增加 `country`/`category`/`importance_min`/`offset` 与 `meta.total` |
| 7 | 自选只能增删/排序，不能改分组与优先级 | 新增 `PATCH /api/watchlist/{symbol}`（group/priority/note） |

> 所有改动均为**增量/可选参数**，旧调用与旧响应字段保持兼容（前端旧调用重载也保留）。

## 2. 新增/增强接口契约

### 2.1 `GET /api/overview`

单请求返回总览页全部数据。可选参数：`calendar_limit`（默认 6）、`alerts_limit`（默认 5）。

```jsonc
{
  "asof": "2026-11-13T22:59:00+00:00",
  "health": { "status": "ok", "version": "1.2.0", "env": "local", "llm_enabled": false,
              "time_local": "...", "database": {...}, "scheduler": {...}, "counts": {...} },
  "brief": { "id": "...", "kind": "manual", "trade_date": "2026-11-13", "created_at": "...",
             "markdown": "...", "meta": {...} } | null,
  "snapshot": { "data": [ { "symbol": "AU", "unit": "元/克", "contract_size": 1000, ... } ],
                "meta": { "asof": "...", "count": 35, "with_quote": 35 } },
  "watchlist": { "data": [ { "symbol": "AU", "unit": "元/克", "spark": [839.0, ...], ... } ] },
  "macro": { "latest": [ { "code": "US10Y", "value": 5.15, ... } ],
             "sparks": { "US10Y": [4.9, 5.0, ...] } },
  "alerts": { "unread": 10, "items": [ { "id": "...", "level": "warn", ... } ] },
  "calendar": [ { "id": "...", "ts": "...", "name": "...", "country": "美国", "importance": 3 } ],
  "jobs": { "total": 23, "failed": 0, "scheduler_running": true, "next_run": "..." }
}
```

### 2.2 行情单位

- `GET /api/market/snapshot`：每条新增 `unit`（如 `元/克`、`美元/盎司`、`元/吨`、`点`、`汇率`）与 `contract_size`。
- `GET /api/watchlist`：每条新增 `unit`；聚合接口额外返回 `spark`（最近 30 根日线收盘）。
- 单位来源：`backend/app/platform/instrument_units.py` → `init_db.seed_instruments` 写入 `instruments.extra.unit`，可通过 `extra` 覆写。

### 2.3 简报

| 端点 | 说明 |
|---|---|
| `GET /api/briefs/latest?kind=daily\|weekly\|monthly` | `daily` 聚合 `manual/premarket/postmarket`；返回 `{data, neighbors:{previous_id,next_id}}` |
| `GET /api/briefs?kind=&limit=&offset=` | 历史列表；`meta:{count,total,offset,has_more,kinds}`；按 `trade_date` 倒序 |
| `GET /api/briefs/kinds` | `{data:{kinds, groups:{daily,weekly,monthly}}}`，供 tab 徽标 |
| `GET /api/briefs/{id}` | 按 id 取正文（历史期次） |

### 2.4 事件 / 新闻 / 日历

| 端点 | 新增参数 | 新增响应字段 |
|---|---|---|
| `GET /api/events` | `type`、`q`、`instrument`、`offset` | `impact`、`document_id`、`document_ids`、`meta.total` |
| `GET /api/news` | `q`、`source`、`tier`、`since_days`、`offset` | `source_id`、`meta.total` |
| `GET /api/calendar` | `country`、`category`、`importance_min`、`offset` | `meta.total`/`meta.days` |

> 事件 `source_ids` 即原始 document id，前端点击事件行可直接打开证据抽屉；无原文的事件不可点。
>
> 事件类型实际枚举：`trade` / `monetary_policy` / `supply` / `geopolitical` / `data_release`（前端 chips 已按真实值映射为 贸易/货币/供给/地缘/数据）。`impact` 目前由抽取规则统一给 `0.3`，前端按 ≥0.7 高 / ≥0.4 中 / 其余低显示；后续抽取质量提升后自动分层。

### 2.5 持仓 / 自选

- `GET /api/positions/products` → `{trade_date, data:[{product,name}]}`。
- `PATCH /api/watchlist/{symbol}` body `{group?, priority?, note?}`；语义：字段「未提供」= 不修改，显式 `null`/空串 = 清空（group/note）。未知标的 404。
- `GET /api/alerts` 新增 `meta:{count, unread}`；总览与顶栏/告警抽屉统一使用全库未确认数。

## 3. 前端联调要点

1. **总览**：`usePolling(getOverview, interval=设置刷新秒数)`；自选迷你走势直接用 `watchlist[].spark`，取消 7 次日线请求；利率日变动由 `macro.sparks` 末两点计算；告警/日历/任务取自聚合结果；保留顶栏 store 轮询。
2. **市场**：价格单位全部用 `item.unit`；会员下拉用 `/api/positions/products`。
3. **简报**：日报/周报/月报 tab 传 `kind`；上一期/下一期用 `neighbors` 或历史列表加载 `getBrief(id)`；空邻居禁用按钮。
4. **论点与证据**：新闻搜索框调用 `getNews({q, limit:20})`；事件类型 chips + 证据跳转；日历国家/高重要性筛选。
5. **自选管理**：内联编辑分组/优先级/备注，保存 `updateWatch` 后 reload。
6. **旧版兼容**：`?doc=` / `?history=` / `?brief=` / `?theme=` 等深链不变。
