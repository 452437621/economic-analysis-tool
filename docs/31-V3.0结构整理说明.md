## 5. 跨平台脚本

`scripts/epic.py` 是唯一实现（标准库），动作：

`setup / start / stop / restart / status / build / dev / ci / selfcheck / check-acceptance / backup / restore / maintain / snapshot / screenshots / lint`

每个动作提供三份薄包装：

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows PowerShell 5.1/7 | `<action>.ps1` | UTF-8 BOM；参数映射到 CLI |
| Windows cmd.exe | `<action>.cmd` | ASCII + `chcp 65001`；`%*` 透传 |
| Linux/macOS bash | `<action>.sh` | LF；`exec` venv Python |

示例：

```powershell
.\scripts\start.ps1 -NoBrowser -Port 8766
.\scripts\status.ps1 -Json
```

```bat
scripts\start.cmd --no-browser --port 8766
scripts\status.cmd --json
```

```bash
./scripts/start.sh --no-browser --port 8766
./scripts/status.sh --json
```

关键兼容点：

- PID 文件：`data/run/epic.pid`，含 `pid/server_pid/port/started_at/arguments/python/root/cwd`。
- 后台脱离：Windows `DETACHED_PROCESS`，POSIX `start_new_session`。
- 归属校验：命令行含 `app.serve`/`app.main:app` 且位于仓库内；PowerShell 查询强制 UTF-8 输出，避免 `chcp` 影响。
- 端口：`--port` > `.env` `EPIC_PORT` > 8765；Vite 代理读取同一变量。
- `_common.ps1` 已删除；`check_acceptance.ps1` 更名为 `check-acceptance.ps1`（与 action 对齐）。

## 7. 审查发现与处置

已修复（本次审查确认）：

- `jobs/supervisor.py`：`run_schedule_check` 的审计写入失败不再跳过 `_CHECK_LOCK.release()`（嵌套 `finally`）。
- `jobs/supervisor.py`：`assess_readiness` 的 `bars_ok` 现在要求 `REQUIRED_BARS` 中每个标的自身新鲜（此前只看全局最新一根）。
- `lens/position.py`：`long_bond` 的空头止损改为收益率下行（此前无论多空都放在上方）。
- `frontend/src/utils/cycleFormat.ts`：`ICI=内部秩序`、`ECI=外部秩序`（与 `config/cycle.yaml` 一致）。
- `frontend/src/composables/usePolling.ts`：首轮请求未完成即卸载时不再创建定时器/监听器。
- `timeline/engine.py`：`run_timeline(today=date)` 不再对 `date` 调用 `tzinfo`；`/api/v2/timeline/overview` 的 `degraded_reasons` 归一为数组。
- `frontend/src/api/types/ledger.ts` + `LedgerView.vue`：降级原因按 `{code,message,severity}` 渲染，与后端一致。
- `api/trades.py`：无亏损时 `profit_factor` 返回 `null`（此前错误显示 0.00），前端显示 `—`。

暂缓（会改变模型输出或产品口径，需单独评审）：

- 各透镜在输入缺失时仍以 0 参与合成分（`fed_state` / `song_state` / `layers_*` / `persona_engine`）。这是既有产品口径，改为 `None` 会改变共识分与历史输出，不在本次行为保持型重构内。
- `cycle/analogs.py` 的稀疏候选余弦相似度、`cycle/sustainability.py` 的负 r−g 模式回退。均属既有算法口径，需单独设计变更。
