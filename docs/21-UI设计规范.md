# 21 UI 设计规范（V2.0 设计系统）

> 基线：`docs/design/mockup/`（V1.5 静态原型，深/浅双主题）+ V2.0 交互原型 `docs/design/mockup-v2/`
> 关联：[18 总案](./18-V2.0改造总案.md)｜[19 透明化](./19-透明化业务流程设计.md)｜[20 功能与接口](./20-功能与接口设计.md)
> 这份规范的目标只有一个：**让「可信」这件事看起来就可信**——信息密度高、层级清楚、不确定的地方一眼能看见。

---

## 1. 设计原则

| # | 原则 | 具体表现 |
|---|---|---|
| 1 | **数字优先** | 页面第一眼看到的是数值与变化，不是装饰；装饰性元素几乎为零 |
| 2 | **透明可见** | 每个结论旁边有置信度与证据等级；降级/缺失/滞后必须有徽标，禁止静默 |
| 3 | **密而不乱** | 高信息密度，但用留白、分组线、字号层级区分；不靠颜色堆叠 |
| 4 | **可下钻** | 任何数字/结论都是入口；下钻用统一的抽屉，不跳页 |
| 5 | **红涨绿跌** | 中国市场习惯；色盲友好模式提供「▲▼ + 正负号」兜底 |
| 6 | **等宽数字** | 所有数值用 tabular-nums，保证纵向对齐、便于扫读 |
| 7 | **一屏一结论** | 每个页面顶部有「一句话判断」，往下才是证据 |
| 8 | **暗色为默认** | 长时间盯盘护眼；浅色为白昼/打印场景 |

### 2.3 语义色（与数据状态绑定，禁止挪作装饰）

| 状态 | 色 | 出现位置 |
|---|---|---|
| 证据等级 E0 | 灰 `--dim` | 徽标 |
| E1 | 青 `--accent` | 徽标 |
| E2 | 蓝绿 `#38BDF8` | 徽标 |
| E3 | 紫 `#A78BFA` | 徽标 |
| E4 | 橙 `--warn` | 徽标 + 斜纹底 |
| 降级 | `--warn` 边框 + 图标 | 顶栏/卡片 |
| 失效条件命中 | `--danger` | 结论卡 |
| 数据陈旧 | `--dim` 虚线 | 数值下划线 |

**置信度色阶**：≥0.8 `--up`（绿？注意与涨跌色冲突）→ 这里改用独立的青色系避免语义混淆：

| 置信度 | 色 |
|---|---|
| ≥0.80 | `#3DD68C` |
| 0.65–0.79 | `#4CC2FF` |
| 0.50–0.64 | `#F5A524` |
| 0.35–0.49 | `#F08C4C` |
| <0.35 | `#64748B` |

> **规则**：红/绿只用于涨跌，不得用于置信度或风险等级，避免「涨=好=可信」的认知混淆。

## 3. 字体与字阶

```
--font-sans: "Inter", "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", ui-monospace, "Cascadia Code", monospace;
```

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 32/40 | 600 | 页面主结论数字 |
| H1 | 22/30 | 600 | 页面标题 |
| H2 | 16/24 | 600 | 区块标题 |
| Body | 13/20 | 400 | 正文 |
| Small | 12/18 | 400 | 表格/说明 |
| Micro | 11/16 | 500 | 徽标/标签（大写或加字距） |
| Mono | 13/20 | 500 | 所有数值、代码、ID |

规则：
- 数值一律 `font-variant-numeric: tabular-nums`；
- 涨跌数值带符号（`+0.32`），单位用小字号；
- 中文正文不用 `letter-spacing`；英文全大写标签用 `0.04em`。

## 5. 布局栅格

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 56px：Logo ｜ 数据时点/运行ID ｜ 降级徽标 ｜ 搜索 ｜ 主题 ｜ 设置 │
├────────┬─────────────────────────────────────────────────────┤
│ 侧栏   │ 内容区（padding 24，最大宽 1600，居中）              │
│ 232px  │  ┌ 页头：标题 + 一句话结论 + 操作区 ────────────┐   │
│ 可折叠 │  ├ 主区：12 栏栅格，gap 16 ─────────────────────┤   │
│ 至 64  │  └──────────────────────────────────────────────┘   │
└────────┴─────────────────────────────────────────────────────┘
```

- 设计基准 **1440×900**，最小支持 **1280×720**；
- 12 栏栅格，常见分栏：4/8、3/6/3、6/6、8/4；
- 卡片内 padding 16；卡片间 gap 16；区块间 24；
- 侧栏可折叠（`⌘/Ctrl+B`），折叠后 64px 只留图标；
- **不使用**响应式移动端布局（个人桌面工具），但保证 1280 可用。

## 6. 核心组件规范

### 6.1 指标卡 `<MetricTile>`

```
┌───────────────────────────────────┐
│ 美国 · CPI 同比            [E1] ⓘ │
│  3.70%        ▲ +0.30pp           │
│  前值 3.40%   区间 1914–2026       │
│  均值 3.29%   最高 23.70%(1920)    │
│  频率 每月 · 季调 NSA · 下次 12-10 │
└───────────────────────────────────┘
```

- 固定 8 字段（TE 标杆）；
- 值 hover 出下划线与「查看来源」；
- 右上角证据徽标可点；
- 底部「下次发布」是差异化信息，必须有。

### 6.2 置信度徽标 `<ConfidenceBadge>`

`[ 73% 较可能 ]` —— 数字 + 措辞 + 底色；hover 显示构成（覆盖率/一致性/校准/陈旧）。

### 6.3 「为什么」抽屉 `<WhyDrawer>`

```
┌ 为什么是这个结论？                        ✕ ┐
│ 结论：美国处于长债务周期晚期（财政主导）      │
│ 置信度 66% · 证据 E3 · asof 2026-11-17       │
├──────────────────────────────────────────────┤
│ ▸ ① 贡献分解   瀑布图                         │
│ ▾ ② 规则命中   3 条                           │
│    R-BC-03 …（条件、权重、出处）              │
│ ▸ ③ 特征值     18 项（表）                    │
│ ▸ ④ 原始观测   带来源与修订号                 │
│ ▸ ⑤ 反对证据   2 条 + 失效条件                │
├──────────────────────────────────────────────┤
│ [导出这段推理]              [反事实试算 →]    │
└──────────────────────────────────────────────┘
```

- 右侧滑出，宽 560px（原型实测值；窄屏 `92vw`），遮罩 `rgba(0,0,0,.5)`；
- 分节懒加载；`Esc` 关闭；焦点回到触发元素；
- 移动端（<1280）改为全屏。

### 6.4 表格

| 规则 | 说明 |
|---|---|
| 行高 | 36px（密）/ 44px（舒） |
| 表头 | `--surface-2`，12px 加粗，粘性 |
| 数字列 | 右对齐，等宽 |
| 涨跌 | 红涨绿跌 + ▲▼ |
| 排序 | 点击列头，三态（无/升/降） |
| 空值 | `—` 灰 |
| 行操作 | hover 出现，不占常驻空间 |
| 长表 | 虚拟滚动（>200 行） |

### 6.5 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | `--accent` 底 + 深色字 | 主操作（每个视图最多 1 个） |
| Secondary | 透明底 + `--border-strong` | 次操作 |
| Ghost | 无边框 | 行内操作 |
| Danger | `--danger` | 删除/作废（二次确认） |
| Size | 28 / 32 / 36 | 表格内/常规/页头 |

### 6.6 徽标与标签

- `E0–E4` 证据等级：11px、胶囊、带底色；
- `降级`：`--warn` 描边 + 图标，hover 显示原因；
- `陈旧`：虚线底边 + 时间；
- `新` / `改` / `争议`：小胶囊。

### 6.7 空状态 / 加载 / 错误

| 状态 | 设计 |
|---|---|
| 空 | 居中小图标 + 一句解释 + 一个操作（如「运行一次分析」） |
| 加载 | 骨架屏（保持布局，不出现转圈整页） |
| 错误 | 错误码 + 人话 + 「重试」+ 「查看日志」 |
| 降级 | 顶部黄条 + 受影响的卡片角标 |
| 无权限/不可用 | 灰化 + 说明（本机工具基本不出现） |

## 7. 图表规范（ECharts）

### 7.1 主题

| 项 | 值 |
|---|---|
| 背景 | 透明（继承卡片） |
| 网格线 | `--border`，仅横向，虚线 |
| 坐标轴文字 | `--muted` 11px |
| 轴线 | `--border-strong` |
| 数据色序 | `#4CC2FF, #A78BFA, #F5A524, #3DD68C, #F0544F, #38BDF8, #F08C4C, #94A3B8` |
| 提示框 | `--surface-2` + `--border-strong` + 阴影，等宽数字 |
| 图例 | 顶部右对齐，可点击隐藏 |

### 7.2 图表类型与用途

| 用途 | 图型 | 备注 |
|---|---|---|
| 单序列趋势 | 折线（面积可选） | 标注关键事件（竖线 + 标签） |
| 跨国实力对比 | 堆叠/面积图 | 6 国，颜色固定，可播放 |
| 周期带 | 阶梯带（heatmap band） | 每层一行，色块表示阶段 |
| 五层周期 | 同心圆罗盘 | 自定义 series |
| 贡献分解 | 瀑布图 | 正负色 + 残差高亮 |
| 情景概率 | 水平条 + 标签 | 概率和 100% |
| 校准 | 可靠性曲线 + 直方图 | 45° 参考线 |
| 相关性 | 热力矩阵 | 发散色阶（红负/蓝正） |
| 时间轴 | 自定义 graphic 泳道 | 可缩放、可播放 |
| DAG | 力导向/分层布局 | 节点状态色 + 边动画（运行时） |

### 7.3 规则

- 每张图必须有**标题 + 单位 + 数据时点**；
- Y 轴不从零开始时必须标注 `⤬` 截断符号；
- 缺失数据用断点，不插值；
- 异常点（|z|>3）用空心圆标注，hover 说明；
- 提供「表格视图」切换（可访问性）；
- 禁止 3D、禁止饼图（除占比 ≤4 类）、禁止双 Y 轴（除明确标注）。

## 9. 动效

| 场景 | 时长/曲线 |
|---|---|
| 抽屉滑出 | 240ms `cubic-bezier(.2,.8,.2,1)` |
| 数值变化 | 300ms 数字滚动（仅关键指标） |
| 图表加载 | 400ms 渐入，数据先出后动画 |
| 骨架屏 | 1.2s 呼吸 |
| 时间轴播放 | 可调 0.5/1/2/4x |

**禁止**：弹跳、旋转加载超过 1s、视差滚动。

---

## 10. 主题与打印

- 深浅色一键切换，跟随系统可选；记住用户选择；
- 打印/PDF：自动切浅色、隐藏侧栏与操作、保留数据时点与证据脚注；
- 导出图片：2x 分辨率，白底。

---

## 11. 可访问性

| 项 | 要求 |
|---|---|
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1 |
| 色盲 | 提供「色盲友好」模式：涨跌用蓝/橙 + ▲▼ + 符号 |
| 键盘 | Tab 顺序合理；抽屉/弹窗焦点陷阱；快捷键：`g d`今日、`g c`周期、`g l`长河、`/`搜索、`?`帮助 |
| 屏幕阅读器 | 图表有 `aria-label` 与表格替代 |
| 动效 | 尊重 `prefers-reduced-motion` |

## 13. 验收

| # | 项 | 标准 |
|---|---|---|
| U1 | Token 一致 | 全站颜色/字号/间距只来自 token，无硬编码 |
| U2 | 透明可视 | 每个结论卡有置信度 + 证据徽标 |
| U3 | 降级可见 | 人为断源后顶栏与卡片有明确提示 |
| U4 | 1440 与 1280 | 两档宽度下无横向滚动、无重叠 |
| U5 | 键盘可达 | 主路径可纯键盘完成 |
| U6 | 对比度 | axe 检测无 serious 级问题 |
| U7 | 打印 | 导出 PDF 布局正确、脚注完整 |
