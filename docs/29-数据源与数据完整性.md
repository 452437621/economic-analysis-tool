## 3. 数据缺口与替代方案

| 缺口 | 状态 | 影响 | 替代/处置 |
|---|---|---|---|
| COMEX 白银库存 | 无免费源 | 宋鸿兵 S9 白银挤兑规则恒为 `unknown` | 用 `LBMA_SILVER_TONNES` + 金银比做代理，UI 明示 |
| IMF COFER 储备货币份额 | IMF 接口 403 | 无法验证「美元储备份额下滑」 | 引用静态研究口径，标 E3 |
| CIPS / 人民币跨境收支 | 无公开 API | 人民币国际化只能叙事 | 已列入 data_gaps |
| HY OAS 高收益债利差 | FRED 不可达 | 美联储透镜的信用腿缺失 | 用 SPX 回撤 + SOFR−EFFR 代理 |
| ACM 期限溢价 | NY Fed CSV 返回 HTML 壳 | 无法拆解期限溢价 | 用 30s10s + 实际利率代理 |
| M2 长历史 | H.6 仅当前页 | 5 年分位不可算 | `WB_US_M2_GDP` 年频 + 17 个月月频 |
| 中国房价/销售 | 无免费源 | 宋鸿兵 S14 未工具化 | 列入未工具化清单 |
| 财政脉冲（payload 季度口径） | 需 CBO/OMB 季度数据 | 只有 TTM 近似 | 用 TTM 赤字/GDP 近似 |

**原则：缺口不填占位值。** 缺失读数一律返回 `None` + `missing_reason`，规则状态记为 `unknown`，并在 `data_gaps` 与页面横幅里逐条披露。

## 4. 数据完整性机制

1. **独立降级**：每个数据源单独 `try/except`，失败写入 `stats["degraded_reasons"]` 与 `record_health(ok=False)`，不影响其它源。
2. **缺失即 NaN**：透镜表达式遇到未知列返回全 NaN 序列，读数变 `None`，不会抛异常中断整条管线。
3. **面板对齐**：`load_panel()` 宏观 ffill 7 天、行情 ffill 5 天；人物/层引擎再对低频序列 `ffill(limit=800)`，保证月频/年频参与比值计算。
4. **幂等落库**：`macro_obs` 按 `(series_id, ts_utc)` upsert；`(code, asof, vintage_date)` 观测幂等，重复运行不产生重复行。
5. **可追溯**：每次运行写 `analysis_runs` / `analysis_steps`，读数落 `observations`，规则命中落 `rule_hits`。
6. **新鲜度检查**：`check_data_quality` 每日 15:50 检查新鲜度/覆盖/连续性；`/api/v2/system` 展示健康状态。

## 5. 新增数据源的标准做法

1. 在 `backend/app/ingest/providers/` 写 `xxx.py`：只负责「取数 + 解析」，异常统一抛 `ProviderError`。
2. 在 `backend/app/ingest/pipeline.py`：
   - 加 `SOURCE_XXX = dict(name=..., kind=..., tier=..., reliability=..., base_url=...)`；
   - 在 `MACRO_SERIES_META` 登记 `{name, unit, country, freq}`；
   - 在对应 `collect_*()` 里加一段，落库用 `_store_macro_points`，失败记 `degraded_reasons`。
3. 加离线测试：`tests/test_*_sources.py` 用 monkeypatch 替换抓取函数，断言解析结果与落库契约（**必须 patch，不允许测试联网**）。
4. 在 §2 的表格里补一行，并在 `config/lens.yaml` 的 `data_gaps` 里删掉已被填上的缺口。
5. 如果新序列要参与透镜读数，同时更新 `backend/app/lens/{fed,song,layers,personas}/*.yaml` 的表达式并在 `docs/27` 或 `docs/28` 记录。
