## 1. 为什么是多透镜而不是一个模型

两套框架回答的问题不同，强行合成一个分数会丢掉最重要的信息——**它们什么时候分歧**。

| | 美联储透镜 | 宋鸿兵透镜 |
|---|---|---|
| 核心问题 | 央行会怎么反应？金融条件会不会被迫放松？ | 美元流动性环流在变热还是变冷？秩序溢价在不在？ |
| 自变量 | 实际利率、金融条件、增长/通胀象限、资产回撤 | 美元外部价格 + 回购市场「心脏」+ 财政货币化 + 央行购金 |
| 时间尺度 | 3–18 个月（政策周期） | 3–10 年（长债务周期），叠加 3/6 年短周期 |
| 对黄金 | 实际利率的机会成本 | 全球化「熵值」的尺度，不是避险资产 |
| 典型误用 | 用估值预测联储转向 | 用叙事替代回购市场读数 |

合成层因此只做三件事：给出一致度、列出分歧与催化、把多数透镜都认可的资产排前面。**分歧本身是输出，不是要被平均掉的噪声。** 2026-11-19 起同一形式扩展到 13 套透镜（宏观层、微观层与九位思想者），见 §12。

## 2. 数据基础与证据等级

各套透镜共用 `app.cycle.market.load_panel()` 的日频面板（宏观序列 + 日线，宏观 ffill 7 天、行情 ffill 5 天），加上 `gold_metrics` 的黄金/白银/央行购金序列。所有读数都是本地库的纯函数，不联网，保证同一输入可复现。

证据等级沿用全站口径：

- **E2**：本地可复核的实时序列（如 US10Y、DXY、SOFR−EFFR）；
- **E3**：由多条 E2 推导或含人工配置权重（如 stance、环流相位）；
- **E4**：叙事/定性判断，不得单独构成交易信号。

当前**已接入**：EFFR、SOFR、SOFR−EFFR、US2Y/5Y/10Y/30Y、US10Y_REAL/US5Y_REAL、US10Y_BE/US5Y_BE、DXY、SPX/NDX、XAUUSD、SI、CU、BZ、CL、000300、HSI、USDCNH、USDCAD、USDJPY、JP30Y、US_FED_DEBT、WB_US_GDP、WB_US_CPI、US_MTS_*、CB_GOLD_GLOBAL_TONNES、CN_GOLD_RESERVES_USD、COMEX 黄金库存、SGE 黄金租赁利率、中金价差。

**明确缺口**（在 UI 与 `/state` 的 `data_gaps` 中逐条披露，不填占位值）：

| 缺口 | 影响 |
|---|---|
| COMEX 白银库存 | S9 白银挤兑规则只能显示 `unknown` |
| IMF COFER 储备货币份额 | 无法实时验证「美元储备份额下滑」 |
| CIPS / 人民币跨境收支 | 只能引用静态研究口径，不能做信号 |
| 高收益债利差（HY OAS） | Fed 透镜的信用腿只能用品股/金融条件代理 |
| ACM 期限溢价 | 无法把长端拆成「预期 + 期限溢价」 |
| M2 长历史 | 已接 H.6（月频），但官网只给当前页，仅 17 个月；长期用 `WB_US_M2_GDP` 年频兜底 |

> 2026-11-19 更新：M2、联邦资产负债表（H.4.1）、货币市场（TGCR/BGCR/OBFR/RRP）与财政脉冲均已接入，缺口表对应删减；数据源细节见 [`docs/29`](29-数据源与数据完整性.md)。

## 3. 美联储透镜（`lens.fed.v1`）

### 3.1 21 条读数

`effr`、`real_policy`（EFFR−BE10）、`real10`、`real5`、`curve_2s10s`、`curve_5s30s`、`be10`、`be5`、`sofr_effr`、`dxy`、`fci`、`growth`（铜金比 z）、`inflation`（BE10 z）、`spx_drawdown`、`spx_valuation`、`ndx_ratio`、`gold_real_corr`、`unemployment`（年度低频，仅作方向校验）、`payload`（缺，财政脉冲）、`hy_oas`（缺）、`m2`（缺）。

每条带 `value / change / z / percentile / source / evidence / missing_reason`，前端网格直接渲染。

### 3.2 立场分与象限

- **stance（0–100）**= 加权分位：实际 10Y 利率 0.30、实际政策利率 0.20、金融条件 0.30、（1−曲线）0.20。越高越紧。
- **FCI** = mean(−z(SPX 63 日收益), z(DXY 63 日收益), z(real10 63 日变化), z(SOFR−EFFR))，至少两条腿才算。
- **regime**：增长 z × 通胀 z 四象限（复苏 / 过热 / 滞胀 / 衰退）。
- **Fed Put**：以 52 周高点 ×0.85 为行权线，按回撤 <8% / 8–15% / >15% 分「远 / 接近行权 / 行权区」。
- **policy**：宽松倾向 / 紧缩倾向 / 观望 + 未来 3 个月降息概率（由 growth、inflation、stance 映射，非市场定价）。

### 3.3 资产评分（−2…+2）

7 类：美股、黄金、白银、美元、长端美债（评分方向为**债券价格**）、A 股、商品（Brent）。公式围绕增长/通胀/实际利率/美元/立场/宽松预期/Fed Put/金—实际利率相关；系数目前硬编码在 `backend/app/lens/fed.py` 与 `song.py`（`synthesis.weights` 只配置两镜合成权重）。

### 3.4 规则 F1–F12

| 规则 | 触发要点 |
|---|---|
| F1 | 实际利率转正且上行 |
| F2 | 深度负实际利率（金融抑制） |
| F3 | 2s10s 倒挂 ≤ −30bp |
| F4 | 曲线由倒挂转正（熊陡/牛陡） |
| F5 | FCI 三个月收紧 ≥ +0.8σ |
| F6 | 标普回撤 ≥ 10% |
| F7 | BE10 > 2.8% |
| F8 | 增长 z < −1 |
| F9 | DXY 三个月 +5% |
| F10 | 金—实际利率相关转正（秩序溢价压倒机会成本） |
| F11 | NDX/SPX z > 1.5（集中度风险） |
| F12 | 增长与通胀双负（衰退+通缩） |

每条规则含 `severity`、`falsifier`（失效条件）、`assets`、`sources`；命中写 `RuleHit("lens.F*")`，未命中/缺数据也保留状态（`miss` / `unknown`），不做「沉默即安全」的暗示。

## 4. 宋鸿兵透镜（`lens.song.v1`）

### 4.1 31 条读数

美元外部价格：`dxy`、`dxy_pct`（250 日分位）、`dxy_yoy`、`real10`、`us10y`、`us10y_pct`（5 年分位，注明 60 年数据缺）、`jp30y`、`usdcnh`、`em_relative`（HSI/SPX）、`csi_spx`；
回购心脏：`sofr_effr`、`sofr_spike`（5 日差）；
黄金/白银/铜油：`gold`、`gold_silver`、`copper_gold`、`oil_gold`、`gold_corr`、`cn_premium`、`gold_lease`、`comex_gold_flow`、`cb_gold`、`cn_reserves_yoy`；
财政/秩序：`debt_gdp`、`deficit_gdp`、`interest_receipts`、`us_cpi`；
风险共振：`geo_divergence`（油 z − 金 z）、`dxy_us10y_corr`。

缺口：`comex_silver`、`reserve_share`、`cips`。

### 4.2 美元心脏三态

以 SOFR−EFFR 与 5 日跳升判定：

- **心率杂音**：spread > 3bp；
- **心绞痛**：spread > 8bp 或单日跳升 > 4bp；
- **心肌梗塞**：spread > 15bp 或跳升 > 8bp。

心梗时框架的推论是「机构卖一切换流动性」，**黄金也会先被卖**，之后才分辨避险——这与「乱世买黄金」的直觉相反，是宋氏框架最容易被误读的一点。

### 4.3 环流相位与两套风险

- **phase**：DXY 250 日分位 <35% 且实际利率不升 → 热环流；>65% 且实际利率不降 → 冷环流；其外为过渡；心梗强制「环流反转」。
- **harvest_risk（0–100）**：DXY 分位 0.25、实际利率 0.20、恒指回撤分位 0.20、USDCNH 0.20、SOFR 0.15 的加权。
- **debt_risk（0–100）**：债务/GDP (v−100)/100、赤字/GDP (v−3)/9、利息/财政收入 (v−10)/36、10Y 一年变化，权 0.35/0.25/0.25/0.15。
- **gold_regime**：由黄金综合分分四档（战略配置 / 逢低配置 / 交易持有 / 回避）。
- **entropy 分**：0.45×金—实际利率相关 + 0.30×中金价差 + 0.25×央行购金。

### 4.4 规则 12 条（S1–S5、S7–S13）

S1 热环流、S2 冷环流、S3 心梗、S4 秩序溢价、S5 长端冬季、S7 债务货币化、S8 2035 崩溃路径、S9 白银挤兑（缺数据，`unknown`）、S10 金银比 >85、S11 A 股热钱三段式、S12 战争冲击（油涨金跌）、S13 AI 债务地雷（10Y 一年 +0.5pp）。

> 研究笔记中的 S6（2020 后通胀再热的「三变六反」判据，需 60 年通胀序列）与 S14（中国房地产长周期，需房价/销售数据）因本地库缺可计算指标，**未纳入规则表**；等数据接入后再补，不以固定 `unknown` 占位。

## 5. 合成层

> 本节记录双透镜时代（2026-11-18）的定义；2026-11-19 起改为 13 套透镜加权，权重、一致度四态与分歧成对输出见 §12.3。下列公式仍适用于 fed/song 两套透镜自身的分数口径。

- **consensus** = 0.5×fed + 0.5×song（权重可配；多透镜版按 §12.3 的 13 项权重加权）。
- **agreement**：两镜同向且各自 |score| ≥0.25 → 共振多/空；同向但弱 → 弱信号；反向且 min(|fed|,|song|) ≥0.35 → 分歧。
- **direction**：|consensus| ≥0.25 才给 up/down，否则 flat。
- **probability** = min(0.78, 0.5 + 0.1×|consensus|)（启发式，不是校准概率）。
- **outlook**：90 天 base/bull/bear 三情景 + triggers + invalidators。
- **warnings**：心脏状态、收割风险 ≥65、债务风险 ≥60、Fed Put 行权区、立场 ≥80，以及宏观/微观/人物透镜的 warn/critical 规则与 flags。
- **confidence** = min(0.85, 0.20 + 0.20×fed 覆盖 + 0.15×song 覆盖 + 0.25×一致度 + 0.15×透镜广度)，避免「数据越缺越自信」。
- **cycle_context**：读取最近一条 `cycle.state.world` 的长/短周期与流动性，保证与周期罗盘同源。

## 6. 血缘与可回溯

每次运行在 `analysis_runs` 落一条 `kind="lens"` 的运行，方法注册为：

- `lens.engine.v1`（编排，`app.lens.engine`）
- `lens.fed.v1`（`app.lens.fed`）
- `lens.song.v1`（`app.lens.song`）
- `lens.synthesis.v1`（`app.lens.engine`）

三条推导：`lens.fed.state`、`lens.song.state`、`lens.synthesis`（synthesis 的 `parents` 指向前两条）。读数另写 `observations`：`lens.fed.*`、`lens.song.*`、`lens.score.*`，按 (code, asof, vintage) 幂等。

注意：推导 id 不含 asof，同一天重复运行会 upsert 同一行，**历史轨迹要看 observations**。synthesis 的 value 里带 `rule_metrics` 快照，因此只读接口能在不重跑的情况下重建全部规则状态（含未命中）。

## 9. 研究结论如何进入工具（而不是口号）

- 格林斯潘一脉的可用结论是「**用信用/流动性指标预测反应，不要用估值预测转向**」，因此 Fed 透镜把 FCI、SOFR−EFFR、回撤放在 stance 与规则的核心，估值只作为 F11 的集中度提示。
- 宋鸿兵框架的可用结论是「**美元环流温度是唯一自变量，回购市场是心脏**」，因此 Song 透镜第一屏是相位与心脏状态，而不是黄金目标价。
- 多数透镜（≥2 套且同向、最小 |score| ≥0.25）指向「长端利率中枢上移 + 黄金的秩序溢价」时，合成层才会给出高一致度的长债/黄金判断；只有一套可用时，输出必须标注「单一透镜」并给出催化剂。

## 10. 边界与下一步

- 数据缺口（`config/lens.yaml` 的 `data_gaps` 现为 8 条，另按当日缺失读数动态汇总）未接入前，相关规则只能是 `unknown`；不要用叙事补数字。
- 概率是启发式映射，**不是校准概率**；等预测台账积累 ≥20 条结算样本后再谈 Brier。
- 宋氏「三变六反」（30/60 年）与「过三必变过六必反」（3/6 年）是两套尺度，页面与文案引用时必须注明，不能混用。
- 下一步：接入 COMEX 白银库存与 COFER；接入 60 年通胀序列与中国房价/销售数据后补 S6/S14；对 F/S 规则做 2015–2026 的回测与命中率统计。`lens.<asset>` 预测已进入台账，到期由 `ledger.engine.actual_value` 按标的收盘价（长债按 US30Y 收益率）结算。

| 政策四人体 | `pa.` | 14 | PA1–PA12 | 拉加德/植田和男/贝森特/潘功胜，全球久期第二锚 |

合计：内置 36 条规则 + 人物 93 条规则（9 份 YAML，每份 9–12 条），13 套透镜全部写入血缘（`lens.macro.state`、`lens.micro.state`、`lens.persona.<id>.state`）。

### 12.2 通用人物引擎

`backend/app/lens/persona.py` 不写死任何人，读 `config/personas/*.yaml`：

- **读数**：`expr` 是受限表达式，可用 `z/pctile/chg/pct/yoy/ma/shift/sum12`，列名来自面板（57 条宏观序列 + 35 个标的 + 17 个黄金指标）；
- **沙箱**：AST 白名单 + 空 `__builtins__`，数字开头列名（如 `000300`）先替换为 `SYM_000300`；未知列返回 NaN 使读数降级而不是整页失败；
- **校验**：`validate_spec` 检查重复 id、未知列/函数、severity/field/op 合法、`when` 只能有 `all` 或 `any`、评分必须恰好七个资产键；
- **新增一位人物** = 新增一份 YAML + 在 `config/lens.yaml` 的 `synthesis.weights` 加一行权重，无需改代码。

### 12.3 权重与一致度

- 权重合计 1.000：fed 0.17、macro 0.16、song 0.14、micro 0.125、dalio/druckenmiller/marks 各 0.05、gundlach/el_erian/pozsar 各 0.045、pettis/koo/policy_actors 各 0.04。**人物透镜是交叉验证，不是投票主力。**
- 每个资产只对**当日有评分**的透镜加权（缺透镜不按 0 计），因此覆盖率会随数据完整性变化。
- 一致度判定（实现见 `_agreement_multi`）：**全部可用透镜同向且每个 |score| ≥0.25** → 共振多/空（≥3 套且 |共识| ≥0.6 时升级为「共振强信号」）；**多空两侧各出现 |score| ≥0.35 的透镜** → 分歧（输出「最强多 vs 最强空」的成对分歧）；其余 → 弱信号；只有一套可用 → 单一透镜。透镜越多，共振越难成立——这是刻意的：13 套里只要有 2 套强反向就不该按共识重仓。

### 12.4 调度

透镜每日 16:25（`lenses_daily`）运行，位于 `analyze` 16:10 之后、`decide` 16:30 之前，结果进预警台；补跑由 `jobs/catchup.py` 的 `lenses` 条目负责，种子时间写在 `init_db.py` 的 `JOBS_DEFAULT`。

### 12.5 与双透镜的差异

- 双透镜时代，分歧是「两镜打架」；现在分歧是**哪两套框架打架**，并给出可观测的催化剂；
- 人物透镜命中只是「机械复刻」，推导里显式声明**不代表本人当前观点**；
- 所有新增读数仍遵守证据等级：可交易价格 E2、公开统计 E2、结构判断 E3–E4。

### 12.6 仓位、止损与组合权重（2026-11-19 追加）

方向有了之后，合成阶段再落一层「怎么下注」，实现见 [`backend/app/lens/position.py`](../backend/app/lens/position.py)，纯函数、无数据库依赖，可单测：

| 要素 | 规则 | 依据 |
|---|---|---|
| 止损距离 | `2 × ATR%(14)`，夹在 1.5%–8% | 波动自适应：低波资产不给过宽止损，高波资产不被噪声扫掉 |
| 单笔风险预算 | `1% × |共识分|`，夹在 0.3%–2% | 共识越强给越多风险，但上下限防止单一资产吃掉组合 |
| 单资产权重 | `风险预算 / 止损距离`，上限 30% | 权重是风险的函数，不是「觉得该重仓」的函数 |
| 组合约束 | 总敞口 ≤ 80%、组合风险（各仓位风险之和）≤ 6%，超限等比缩放 | 同时刻全部止损触发的账面上限可控 |
| 观望条件 | `|共识分| < 0.25` 不建仓，权重记 0 | 方向不明时不给仓位，避免「为了满仓而凑仓」 |

- 长债用收益率表达止损（30Y 上行约若干 bp），其余资产用价格表达；止损位、理由句都写进 `plan.stop_level` / `plan.rationale`。
- 权重基准是「总权益 = 100%」，**与账户余额无关**；组合层输出 `gross/long/short/net/cash`、`portfolio_risk_pct` 与五条规则，可从 `/lenses` 合成页与 `synthesis.portfolio` 读取。
- 交易信号侧同步调整（[`backend/app/decision/plans.py`](../backend/app/decision/plans.py)）：手数按标准权益 10 万计算、保留小数手，删除「手数 ≥ 1」「保证金占用 ≤ 50% 权益」两条与资金有关的拦截，改判单笔风险、止损距离、组合权重、名义杠杆、手续费占比。
