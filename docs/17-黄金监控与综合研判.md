### 2.3 中国央行购金的价格重估剔除

`CN_GOLD_RESERVES_USD` 是美元计价的储备规模，会随金价波动。评分时：

```
购金代理% = 储备变动% − 伦敦金现同期涨跌幅%
```

这样 2026-09→10 储备美元值 −5.29%、同期金价 −9.74%，得到购金代理 **+4.45%**，即储备量仍在小幅增加，而非表面上的“下降”。

## 3. 综合评分算法

对每个指标：

1. 取最近 400 期观测（`gold_metrics`），按 transform 归一化到 `-1..1`：
   - `pct_change_1m` / `pct_change_3m`：近 30/90 天变化 ÷ scale；
   - `level`：水平 ÷ scale；
   - `percentile`：历史分位（最近 104 期）；
   - `level_and_change`：实际利率水平与变化加权。
2. 乘以方向：`+1`（央行/ETF/溢价/租赁紧张 → 金价利多）、`-1`（实际利率/美元/库存/投机持仓 → 利空）。
3. 贡献 = 权重 × 方向化得分。
4. 综合分 = Σ贡献 ÷ Σ**已获取**权重 × 100；`coverage` = 已获取权重 ÷ 全部权重。

| 综合分 | 标签 |
|---|---|
| ≥ 50 | 强多 |
| 18 ~ 50 | 偏多 |
| −18 ~ 18 | 中性 |
| −50 ~ −18 | 偏空 |
| ≤ −50 | 强空 |

局限：

- 权重为经验权重（价格/宏观驱动 34、央行 24、ETF 20、租赁/掉期 17、库存与溢价 26、做市商 18，合计 **139**），未做回测优化；
- 不可得指标不参与评分，按已获取权重重新归一，`coverage` 偏低时结论置信度更低；本轮补全后 coverage 由 74% 升至 **100%**，但“全覆盖”不等于结论更准；
- CFTC 分类持仓与银行参与报告是公开可得的最佳代理，不代表 JPM/汇丰等个体做市商实际账簿；
- COMEX 库存来自 MetalCharts 镜像、上海库存以上期所仓单代理、租赁利率以上金所人民币费率代理，均与原始口径（CME / SGE / BIS）存在差异；
- BIS 两项指标权重为 0、默认不参与评分，仍靠手动录入；如启用需先校准口径。

## 4. 采集与调度

```
# 手动采集（约 60-90s，下载 WGC/CFTC/LBMA）
python -m app.jobs.runner --job collect_gold

# 异步触发
curl -X POST http://127.0.0.1:8765/api/gold/refresh
```

- 任务注册：`JOBS["collect_gold"]`（`app/jobs/runner.py`）、`JOBS_DEFAULT`（`app/init_db.py`，16:40）、调度器启动回补 + 每日 16:40（`app/platform/scheduler.py`）。
- 表结构：`gold_metrics`（code + as_of 唯一）、`gold_provider_runs`（数据源健康）。
- 存储幂等：按 `(code, as_of)` upsert，重复运行只更新。
