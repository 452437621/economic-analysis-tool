## 2. 恢复手册（按现象）

### 2.1 数据源失败 / 数据不更新

```powershell
# 1) 看数据源健康与任务状态
#    看板「数据源健康」「任务」；或
Invoke-RestMethod http://127.0.0.1:8765/api/system/sources
Invoke-RestMethod http://127.0.0.1:8765/api/system/jobs

# 2) 手动重跑采集
cd D:\Code\4_个人研发\economic-analysis-tool\backend
$env:PYTHONPATH="..\backend"
.\.venv\Scripts\python.exe -m app.jobs.runner --job collect_quotes
.\.venv\Scripts\python.exe -m app.jobs.runner --job collect_daily_bars

# 3) 看日志
Get-Content ..\data\logs\app.log -Tail 100
```

若仅单一源故障：其余源继续，简报会标注数据缺口；**不要**删除数据库。

### 2.2 行情陈旧 / 告警沉默

- 确认是否非交易时段（周末/节假日）；告警已按品种交易时段判断。
- 检查 `quotes` 最新时点：`/api/market/snapshot`。
- 若交易时段仍陈旧：重跑 `collect_quotes`，检查网络/代理与新浪/东财可达性。

### 2.3 数据库锁 / 写入失败

- 等待重试（内置 4 次退避）；避免同时跑多个重任务。
- 若持续：停止服务 → 备份 → 检查磁盘空间 → 重启。
- 恢复：`scripts\restore.ps1`（默认最新备份，先 DryRun）。

### 2.4 LLM 失败

- 无 Key / 超预算 / 网络失败：任务跳过或简报回退，不影响主流程。
- 查看 `/api/system/health` 的 `llm_enabled`；看板系统卡显示「未配置」。
- 预算守卫：`EPIC_LLM_DAILY_BUDGET_USD`（默认 5 USD）。

### 2.5 页面/接口异常

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\selfcheck.ps1
```

- 自检失败：先看 `data/logs/app.log`；必要时恢复备份。
- 验收失败项会显示在看板「验收与自检」区。

### 2.6 备份与恢复

```powershell
# 备份（热备 + integrity_check）
powershell -ExecutionPolicy Bypass -File .\scripts\backup.ps1

# 恢复（先停服务；默认最新备份；会先校验并保存当前库）
powershell -ExecutionPolicy Bypass -File .\scripts\restore.ps1 -DryRun
powershell -ExecutionPolicy Bypass -File .\scripts\restore.ps1
```

- 备份位置：`data/backup/<时间戳>/`（`epic.db` + `default.yaml`）。
- 回滚副本：`data/backup/pre-restore-<时间戳>/`。
- RPO ≈ 上次备份时间；RTO ≈ 1–2 分钟（复制 + 重启）。
