## 2. 项目背景

### 2.1 用户现状

- 个人投资者，拥有**国内期货账户**（国信期货 App，可交易上期所/大商所/郑商所/中金所/能源中心品种）与 **A 股账户**；**没有境外交易账户**。
- 已形成自己的分析习惯与笔记体系：宏观分析、资产逐项市场分析、交易原则、交易心理、交易系统（见用户提供的 11 份个人笔记，如 `2026-08-09（市场分析）.pdf`、`2026-05-23（宏观分析）.md`、`翟鹏飞.md`、`交易心得.md`、`凯利公式.md` 等）。
- 分析方法论上明显偏好：达利欧的债务周期/机器模型、索罗斯的反身性、德鲁肯米勒的流动性视角、付海棠的供求与"货量要有真凭实据"、翟鹏飞的概率/盈亏比/时间止损体系。
- 关注对象明确：黄金、原油、有色金属、美元与日元、美债与中日欧利率、美股与 A 股（有色重点）、以及特朗普/沃什/贝森特/高市早苗等关键人物的政策动态。

### 2.2 核心痛点

| # | 痛点 | 现状 | 期望 |
|---|------|------|------|
| P1 | 信息过载且碎片化 | 每天从新闻、研报、社交平台、讲话、数据发布中人工筛选，遗漏与重复并存 | 自动汇聚、去重、按资产/主题归档，重要信息主动推送 |
| P2 | 因果链难以追踪 | 知道"美元跌→金价涨"，但说不清当前这波是哪个动力主导、强度多大、是否已被计价 | 每条结论给出可展开的因果链与证据，区分主要动力/次要动力/噪音 |
| P3 | 观点无溯源、易被带节奏 | 二手转述、旧闻新炒、断章取义难以识别 | 原文快照 + 时间戳 + 引用定位 + 可信度评分 + 转载溯源 |
| P4 | 跨市场联动靠感觉 | 汇、股、债、商品、黄金之间的传导时快时慢，人工难以及时更新 | 跨市场传导网络 + 领先滞后统计 + 状态切换预警 |
| P5 | 缺乏历史参照系 | 判断"这次不一样"时缺少可比的宏观状态与历史事件 | 经济周期定位 + 历史类比检索 + 事件窗口结果分布 |
| P6 | 决策与复盘不闭环 | 交易凭盘感，事后难归因；预测对错无记录 | 交易计划卡片 + 预测登记 + 结果校准（Brier/命中率） |
| P7 | 分析产出耗时 | 写一份像样的每日分析要 1–3 小时 | 10 分钟内生成初稿，人工只做判断与编辑 |

### 2.3 一句话定位

**一个本地运行、以证据为中心的个人宏观—市场—交易决策工作台**：把"信息汇聚 → 证据固化 → 因果分析 → 情景推演 → 交易计划 → 复盘校准"做成可重复的流水线，所有结论可一键溯源到原文与时点。

它**不是**行情软件（行情只作为输入），**不是**资讯客户端（资讯只作为原料），**不是**自动交易系统（本阶段只给建议，不碰账户）。

## 3. 用户画像与典型场景

**画像**：单一用户（本人），中文界面，Windows 11 本机使用；每天盘前、盘中、盘后各使用一次，周末做深度复盘；愿意为 API 支付少量费用（待确认）；具备基础编程能力，能按文档启动与排障。

### 场景 1：盘前 07:30–08:30（每日，最高频）

- 打开看板：隔夜外盘（COMEX 金银、WTI/Brent、LME、美股、美债收益率、美元指数、USDJPY、USDCNH）一屏总览。
- 查看**夜间事件流**：美联储官员讲话、财政部动态、特朗普相关、日央行/财务省干预消息、地缘事件；每条带原文链接、发布时间、可信度、影响标签。
- 阅读**自动生成的盘前简报**（按他的笔记风格：分资产、趋势判断、价格区间、影响因素按主/次/弱相关标注、操作要点）。
- 对 2–3 个持仓/候选品种展开"定价逻辑"面板，检查论点与失效条件是否变化。
- 生成/调整**当日交易计划**：方向、入场区、止损、目标、仓位、时间止损、国内对应合约。

### 场景 2：盘中异动（事件驱动）

- 价格异动（如黄金 15 分钟波动 > 1.2σ）触发告警，系统自动检索最近 2 小时新闻与持仓变化，给出"可能原因 + 证据 + 是否可交易"的初步判断。
- 用户点开证据链，确认或否定，并在系统中记录一条人工判断（进入知识库，供后续复盘）。

### 场景 3：盘后 21:00–22:00（每日）

- 自动生成盘后简报：今日市场主线、跨市场验证/背离、持仓与资金流、明日关键日程（数据、讲话、议息、交割）。
- 自动登记预测与交易计划的执行结果（手工确认），用于长期校准。

### 场景 4：周末深度研究（每周）

- 周期定位复核：美国/中国/日本/欧元区的增长—通胀—流动性状态，债务周期阶段是否变化。
- 历史类比：当前状态检索 1970s 滞胀、1985 广场协议、1998 LTCM、2008 GFC、2011 欧债、2013 Taper、2022 加息等阶段，输出"相似点/不同点/后续资产表现分布"。
- 个股深度：以洛阳钼业为例，做商品价格—产量—成本—估值—催化—风险的完整模板分析。
- 系统复盘：预测命中率、信号有效性、模型是否需要修正。

### 场景 5：临时问答（研究助手）

- "如果 12 月美联储不降息，黄金、铜、A 股有色分别怎么走？"系统给出情景树、概率、传导链与历史证据，并明确标注哪些是事实、哪些是推断。

## 4. 产品定位与设计原则

**定位**：个人决策支持系统（Decision Support System），人机协同——机器负责**采集、固化、计算、初稿**，人负责**判断、取舍、下单**。

七条设计原则（后续所有设计以此裁决）：

1. **证据优先（Evidence-first）**：任何结论必须挂接至少一条可定位的证据；无证据只能标注为"待验证假设"，不得作为交易依据。
2. **可信度分层（Trust is earned）**：来源、断言、结论三级打分；冲突信息并列呈现，不平均、不掩盖。
3. **因果可解释（Explainable causality）**：用显式因果图（节点=因子/事件，边=机制+方向+滞后+强度+置信度）表达逻辑，而不是黑箱打分。
4. **区分主次（Dominant vs. Secondary）**：每次分析必须判断当前主导动力，并给出"动力切换"的触发条件。
5. **周期定位（Context first）**：先回答"我们在周期哪里"，再回答"这个资产怎么走"；历史类比是参照系不是预测器。
6. **可执行（Actionable）**：结论最终落到国内可交易的合约/股票、具体价位、仓位、止损与失效条件；不产生"仅供参考"式空话。
7. **可复盘（Falsifiable）**：每个预测/计划都记录概率、时点、失效条件，事后自动对账，让系统越用越准。

## 5. 目标与成功度量

### 5.1 目标（按优先级）

- **G1 信息闭环**：主流信息源自动汇聚，重要信息 30 分钟内进入系统，重复率 < 10%。
- **G2 证据闭环**：简报/结论 100% 可溯源到原文片段；每条结论有可信度标注。
- **G3 逻辑闭环**：覆盖"宏观周期 → 政策/流动性 → 利率/汇率 → 商品/股票 → 国内映射"的完整链条，能输出主要动力判断。
- **G4 决策闭环**：每日产出可执行的交易计划（含价位、仓位、止损、时间止损、失效条件），并与预测登记、复盘打通。
- **G5 效率**：盘前简报从 1–3 小时人工缩短到 10 分钟初稿 + 15 分钟人工修订。

### 5.2 度量指标（上线 8 周后评估）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 结论可溯源率 | 100% | 抽样 50 条结论，检查证据链接有效性 |
| 简报生成时延 | ≤ 10 分钟（含数据拉取与 LLM） | 任务日志 |
| 信息去重率 | ≥ 90% | 人工抽样 200 条 |
| 预测校准 | 季度 Brier 分数优于随机基线 | 预测登记表自动计算 |
| 交易计划完整率 | ≥ 95% 含止损/仓位/失效条件 | 计划表校验 |
| 系统可用性 | 交易时段 ≥ 99% | 心跳监控 |
| 单月 API 成本 | ≤ 预算上限（待确认） | 计费统计 |

### 6.2 明确不做（Out of Scope，V1）

- 国内独有品种（苹果、红枣、花生、玻璃、纯碱、尿素、生猪等）——按用户要求不关注。
- 加密货币、外汇实盘、境外券商账户相关功能。
- 自动下单/程序化交易执行（预留接口，V2 再评估）。
- 高频/日内 tick 级策略（数据成本与合规不匹配）。
- 社交平台爬虫的大规模采集（仅按白名单采集公开 RSS/官方账号，规避反爬与合规风险）。
- 多用户/SaaS 化/移动端 App（V1 为本地单用户 Web）。

## 7. 功能需求

> 编号规则：FR-模块-序号。每条含**描述**与**验收标准（AC）**。P0=首个可交付版本必须；P1=第二阶段；P2=后续。

### FR-1 信息汇聚（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-1.1 | 多源采集：官方（美联储、财政部、白宫、央行、统计局、交易所、EIA、USDA、CFTC）、媒体（路透/彭博标题、国内财经媒体）、研究（投行摘要，若有合法来源）、社交（X 白名单账号） | 配置化数据源，新增源不改代码；每源有采集状态与失败告警 |
| FR-1.2 | 原文固化：保存正文、标题、URL、发布时间、抓取时间、HTTP 元数据、内容哈希 | 任一条目可查看原文快照；哈希可校验；原文不可被覆盖 |
| FR-1.3 | 去重与归并：同一事件的多篇报道归并为"事件簇"，保留各源差异 | 转载/同源识别准确率 ≥ 90%（抽样） |
| FR-1.4 | 实体识别与标注：国家、机构、人物、资产、指标、政策工具 | 抽样 100 条，关键实体召回 ≥ 90% |
| FR-1.5 | 事件抽取：类型（议息、数据发布、讲话、制裁、关税、地缘、供给中断、财报、持仓变化等）、主体、时间、影响资产、方向 | 事件卡片可自动生成，字段完整率 ≥ 85% |
| FR-1.6 | 全文检索与筛选：按资产、事件类型、时间、来源、可信度过滤 | 检索响应 < 1s（10 万条内） |

### FR-2 深度分析（P0/P1）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-2.1 | 宏观状态仪表：增长、通胀、流动性、信用、就业、政策立场六维评分与趋势 | 每周更新；每项有指标来源与计算说明 |
| FR-2.2 | 经济周期定位：美/中/日/欧分别给出"周期象限 + 阶段 + 转换概率" | 输出图 + 文字解释 + 证据 |
| FR-2.3 | 资产定价分解：黄金/原油/铜/债/汇/股指的因子归因（实际利率、美元、库存、风险溢价等） | 给定时间窗，输出各因子贡献度与残差 |
| FR-2.4 | 情景分析：基线/乐观/悲观情景及概率、触发条件、资产影响 | 情景树可视化；概率之和为 100%；每情景有触发信号 |
| FR-2.5 | 人物与机构追踪：关键人物立场卡片、讲话要点、政策反应函数推断 | 讲话入库 ≤ 30 分钟；立场变化有 diff 提示 |
| FR-2.6 | 每日简报自动生成：盘前/盘后两份，按用户笔记风格 | 初稿可读、可编辑、可导出 Markdown/PDF，含证据链接 |
| FR-2.7 | 研究问答：自然语言提问，返回带引用的分析 | 回答中每个事实性陈述有引用；无依据时明确说"证据不足" |

### FR-3 关联分析（P1）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-3.1 | 跨市场相关性：滚动相关矩阵、条件相关、尾部相关 | 支持日/周/月窗；可视化 |
| FR-3.2 | 领先滞后与传导：Granger 因果、转移熵、事件研究 | 输出方向、滞后阶数、显著性、稳定性 |
| FR-3.3 | 因果图（DAG）：节点、机制、方向、符号、滞后、强度、置信度 | 图上可点击边查看证据与历史案例 |
| FR-3.4 | 事件冲击分析：同类事件的历史窗口（T-5 至 T+20）收益分布 | 至少覆盖 50 个历史事件模板 |
| FR-3.5 | 背离监测：历史上稳定联动的资产出现背离时告警（如金价涨/实际利率涨） | 每日扫描，输出背离清单与解释候选 |

### FR-4 溯源取证（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-4.1 | 结论—证据链：结论 → 断言 → 原文片段 → 原文 → 来源 | 任一结论可 3 次点击内看到原文与时间戳 |
| FR-4.2 | 可信度评分：来源历史准确率、多源印证、具体性、时效、利益相关 | 评分有公式与明细，可人工覆写 |
| FR-4.3 | 矛盾检测：同一事实的不同说法并列，标注冲突等级 | 冲突不隐藏；简报中显式提示 |
| FR-4.4 | 转载溯源：识别"新闻源头"与转载链、旧闻新炒（时间倒序） | 输出源头条目与首次发布时间 |
| FR-4.5 | 证据包导出：单条结论或整份简报导出为含快照的 zip/PDF | 离线可读，含哈希清单 |
| FR-4.6 | 审计日志：谁（系统/用户）在何时基于何证据修改了哪条判断 | 全量可查，不可篡改 |

### FR-5 市场风向（P1）

| 编号 | 需求 | 验收标准 |
|---|---|---|

## 9. 数据与内容需求（摘要）

完整清单见 [05-数据源与接口清单](./05-数据源与接口清单.md)。按用途分五类：

1. **市场行情**：国内期货/股票实时与历史、外盘期货与现货、汇率、债券收益率、指数。
2. **宏观数据**：CPI/PCE、非农、GDP、PMI、失业率、库存、货币供应、信贷、财政赤字、国债发行。
3. **文本信息**：央行声明/纪要/讲话、财政部与白宫文件、经济日历、新闻标题与正文、研报摘要、社交动态（白名单）。
4. **仓位与流量**：CFTC COT、SHFE/DCE/CZCE 持仓排名、ETF 份额、13F、TIC、期权 skew/IV。
5. **机构与人物**：关键人物讲话、机构公告、主权基金/对冲基金公开持仓。

数据质量要求：每个数据点必须带**来源、时点、单位、频率、修订标记**；外盘延迟与国内夜盘错配必须显式标注。

### 10.2 交易计划卡模板

```markdown
# 计划 ID TP-YYYYMMDD-01 ｜ 生成时间 ｜ 状态：待确认/已执行/已失效

- 标的：沪金 AU2612（外盘信号：COMEX 黄金）
- 方向：多 ｜ 逻辑一句话：实际利率下行 + 央行购金 + 美元走弱
- 入场区：xxx–xxx（突破/回调确认条件：...）
- 止损：xxx（逻辑：跌破前低/ATR 2 倍）｜ 触发即离场
- 目标：T1 xxx（减半仓）｜ T2 xxx（跟踪止损）

- 失效条件：实际利率反弹 > xx bp / 美元指数突破 xx / 论点证据被证伪
- 证据链：[C7, C8, C9]
- 风险提示：...
```

### 10.3 证据链格式

每条结论后附引用编号 `[Cn]`，展开为：

```
C7 ｜ 来源：美联储 FOMC 声明（2026-09-17 02:00）｜ 类型：一手 / 高可信
     ｜ 原文片段："...inflation remains elevated..."（字符 120–260）
     ｜ 抓取快照：sha256:... ｜ URL: ...
     ｜ 断言：9 月维持利率不变（事实）｜ 可信度：0.92
     ｜ 印证：路透（0.8）、华尔街日报（0.85）→ 一致性：高
```

### 10.4 数字口径规范

- 价格单位、合约乘数、每点价值、保证金比例必须与交易所一致；黄金用美元/盎司（外盘）与元/克（内盘）双口径并给出换算。
- 收益率/利率单位统一：% vs bp 明示。
- 时间统一 Asia/Shanghai 展示，UTC 存储；跨时区事件标注当地时区。
- 概率、置信度统一 0–100%；预测登记必须含时间窗与失效条件。

## 13. 非目标（V1 明确不做）

- 不做社交/跟单/社区功能。
- 不做全市场全品种覆盖（聚焦内外同品种与有色链）。
- 不做毫秒级高频与做市策略。
- 不做自动资金划转、自动下单、自动调仓。

## 14. 验收标准（Definition of Done，V1）

1. 一键启动，浏览器打开看板，无需手工配置环境变量（首次引导配置）。
2. 完成一个完整交易日闭环：盘前简报自动生成 → 盘中异动告警 → 盘后简报 → 预测登记。
3. 抽查任意 20 条简报结论，100% 能展开到原文片段与时间戳；矛盾信息有标注。
4. 对黄金、原油、铜三个品种，能输出"当前价格在交易什么 + 主要动力 + 情景概率 + 国内交易映射"。
5. 至少一个完整交易计划卡通过风控校验，并在事后完成对账与复盘记录。
6. 历史类比功能可返回 Top-5 相似时段及后续资产表现分布。
7. 连续运行 7 天无致命错误；数据源故障有降级与告警。
8. 文档齐全：安装、使用、数据源扩展、故障排查。
