## 1. 总范式：三层世界 + 双向闭环

系统把市场理解为三层嵌套的机器：

```
┌─────────────────────────────────────────────────────────────┐
│ 第一层：实体经济与债务周期（慢变量，月/季度）                  │
│   生产率、人口、债务、信用、库存、政策空间                     │
└──────────────────────────┬──────────────────────────────────┘
                           │ 约束与背景
┌──────────────────────────▼──────────────────────────────────┐
│ 第二层：政策与流动性（中变量，周/月）                          │
│   央行反应函数、财政发债与干预、监管、政治日历                 │
└──────────────────────────┬──────────────────────────────────┘
                           │ 贴现率、流动性、风险偏好
┌──────────────────────────▼──────────────────────────────────┐
│ 第三层：市场定价与博弈（快变量，分/时/日）                     │
│   利率曲线、汇率、商品、股票、黄金；参与者仓位与情绪           │
└─────────────────────────────────────────────────────────────┘
```

**双向闭环**：
- **自上而下（Top-down）**：周期定位 → 政策方向 → 流动性与利率 → 资产配置倾向 → 具体品种。
- **自下而上（Bottom-up）**：品种供需/成本/库存/持仓 → 价格是否偏离 → 反推市场在交易什么 → 修正宏观叙事。
- 两者出现矛盾时，**不强行调和**，而是记录为"背离"，并设置观察触发条件（这往往是最好的交易机会，也是最大的误判来源）。

### 1.1 四套思想体系的系统化映射

| 思想来源 | 核心命题 | 在本系统中的落地 |
|---|---|---|
| 达利欧《原则》《经济原理》 | 经济是机器；短债务周期 5–8 年、长债务周期 75–100 年；四象限；美丽去杠杆；痛苦 + 反思 = 进步 | 周期引擎（EPIC-C）：状态机 + 四象限 + 债务可持续性；情景与原则库；复盘机制 |
| 索罗斯《金融炼金术》 | 反身性：认知改变现实，现实再改变认知；boom-bust 八阶段；可证伪 | 反身性模块：叙事强度 × 价格反馈；泡沫阶段识别（加速→背离→崩溃）；论点必须可证伪 |
| 德鲁肯米勒 | 流动性主导；投资未来而非当下；集中下注；错了立刻认错 | 流动性仪表盘；12–18 个月前瞻；情景集中度；严格失效条件 |
| 付海棠（用户笔记） | 供求决定方向；货量要有真凭实据；成本为锚；物极必反 | 供需平衡表与库存验证；成本曲线；极端估值分位；证据等级"真凭实据" |
| 翟鹏飞（用户笔记） | 概率游戏、复利、盈亏比 ≥3:1、以损定量、时间止损、只做突破 | 交易系统（EPIC-T）：信号、仓位、止损、时间止损、回测 |
| 凯利公式（用户笔记） | 最大化对数增长率；半凯利更稳健；负期望不参与 | 仓位引擎：Kelly 上限 + 半凯利默认 + 期望校验 |

### 1.2 政策三角：沃什—贝森特—特朗普

2026 年的美国政策由三个角色共同决定，系统将其建模为**带约束的联合反应函数**：

- **美联储（沃什）**：目标是通胀信誉 + 强美元 + 金融稳定；约束是债务利息支出与政治压力。反应函数参数：对通胀缺口的敏感度、对失业缺口的敏感度、对金融条件的敏感度、对白宫压力的敏感度（后两者通过讲话文本与市场定价反推）。
- **财政部（贝森特）**：目标是低成本融资 + 债务可持续 + 汇率稳定；工具是发债久期结构（短债/长债）、回购、汇率干预（询价、口头、联合干预、FIMA repo）、金融抑制。
- **白宫（特朗普）**：目标是增长、就业、选举与产业回流；工具是关税、移民、能源价格、对美联储的公开施压、地缘姿态。中期选举（2026-11）构成强政治日历约束。

三者关系不是简单的"谁听谁"，而是**博弈均衡**：例如压低油价以控通胀（白宫）→ 需要美元与地缘配合（财政部/美联储）→ 影响黄金与实际利率。系统用"政策三角状态表"记录每次讲话后的立场变化，并输出**政策情景概率**（如：9 月降息 60% / 维持 30% / 加息 10%），而不是单一预测。

## 2. 周期引擎（EPIC-C）

### 2.1 五层周期嵌套

| 层级 | 周期长度 | 状态变量 | 数据来源 | 对资产的含义 |
|---|---|---|---|---|
| 长债务周期 | 75–100 年 | 债务/GDP、利率水平、货币体系信用 | 历史、BIS、财政数据 | 决定"通胀化债 vs 通缩化债"的大方向 |
| 短债务周期 | 5–8 年 | 信用增速、利率、产出缺口、失业率 | 央行、统计局 | 决定股债商的中期牛熊 |
| 库存周期 | 3–4 年 | 库存/销售比、PMI 库存、产能利用率 | PMI、EIA、交易所库存 | 决定商品 1–2 年的节奏 |
| 信用/流动性周期 | 1–2 年 | 信用脉冲、准备金、RRP、TGA、央行资产负债表 | 央行、财政 | 决定风险资产的"水位" |
| 政治周期 | 2/4 年 | 选举、中期选举、政策窗口 | 日历、民调 | 决定政策冲击的时点与方向 |

### 2.2 状态定义（四象限 + 过渡态）

以**增长（G）**与**通胀（I）**相对趋势的方向定义四象限：

| 象限 | 增长 | 通胀 | 典型资产表现（历史统计，非保证） |
|---|---|---|---|
| 复苏（Reflation） | ↑ | ↓/稳 | 股票 > 商品 > 信用债 > 国债；美元偏弱 |
| 过热（Overheat） | ↑ | ↑ | 商品 > 股票（周期）> 国债（熊）；美元偏强 |
| 滞胀（Stagflation） | ↓ | ↑ | 黄金/商品 > 现金 > 债券；股票承压 |
| 衰退（Deflation） | ↓ | ↓ | 国债 > 现金 > 黄金 > 股票；美元避险走强 |

**过渡态**（系统必须能识别，否则会在拐点反复打脸）：复苏→过热、过热→滞胀、滞胀→衰退、衰退→复苏；以及"假复苏""类滞胀"。

**计算方法**（V1 用规则 + 打分，V2 引入 HMM/马尔可夫切换）：
1. 增长分：PMI 新订单、工业产出、失业率变化、零售、信贷脉冲、OECD 领先指标（按可得性）。
2. 通胀分：CPI/PCE 同比与环比动量、核心服务、工资、租金、商品价格、通胀预期（5y5y、TIPS 盈亏平衡）。
3. 流动性分：央行资产负债表变化、准备金、RRP、TGA、信用利差、金融条件指数。
4. 每个分项做 Z-score 与动量，合成 0–100 分；象限由"水平 + 方向"共同决定。
5. 每个季度人工复核一次权重（防止模型漂移）。

### 2.3 债务可持续性与"化债模式"

对每个经济体计算：

```
利息支出/财政收入、债务/GDP、名义 GDP 增速 - 加权平均利率（r-g）
```

判定三种模式：

| 模式 | 特征 | 政策倾向 | 资产含义 |
|---|---|---|---|
| 通胀化债 | 债务高、r<g、央行容忍较高通胀、货币贬值 | 降息 + 扩表 + 汇率贬值 | 黄金、实物资产、美股名义上涨；长债风险大 |
| 通缩化债 | 债务高、需求不足、物价下行 | 降息 + 财政扩张 + 债务置换 | 债券牛、股票结构性、商品弱；汇率承压 |
| 财政主导 | 央行被迫配合财政、独立性受损 | YCC/干预/金融抑制 | 黄金强、实际利率被压制、货币信用受损 |

> 用户笔记中的判断（美国"通胀化债"、中国"通缩化债"、日本财政主导）是系统要自动复现并持续验证的**假设**，而非写死的结论。系统必须给出支持/反对证据与置信度。

### 2.4 周期→资产映射与置信度

输出不是"现在是过热所以买铜"，而是：

```
象限：过热（置信度 62%）
依据：PMI 52.3（↑）、核心 CPI 3.1%（↑）、失业率 4.2%（→）、信用脉冲 +1.2%
历史映射：该象限下未来 3 个月铜 +4.1%（中位数，n=38），黄金 -1.2%，美债 -2.8%
本次不同点：① 美联储受政治压力 ② 关税冲击供给 ③ AI 资本开支支撑需求
结论：超配铜/油，低配长债；黄金逢回调配置（非趋势性做空）
```

## 3. 政策反应函数与人物追踪

### 3.1 人物/机构立场卡（Stance Card）

每个关键对象维护一张卡片：

| 字段 | 说明 |
|---|---|
| 身份与权限 | 职位、可动用工具、任期约束 |
| 当前立场 | 对通胀/增长/汇率/关税/独立性等的表态（结构化标签） |
| 历史一致性 | 过去 12 个月表态与实际政策的一致率 |
| 影响力权重 | 对市场定价的边际影响（由事件研究估计） |
| 近期言行 | 讲话要点、时间、场合、原文链接 |
| 言行差警报 | 表态与行动背离时提示（"说鹰做鸽"） |
| 情景含义 | 若其立场延续/转变，对应资产影响 |

覆盖对象：沃什（美联储）、贝森特（财政部）、特朗普（白宫）、鲍威尔（前主席/理事）、高市早苗（日本首相）、植田和男（日央行）、贝利（英央行）、拉加德（欧央行）、潘功胜（中国央行）、以及达利欧/索罗斯/德鲁肯米勒（思想框架与公开观点，作为"叙事来源"而非政策主体）。

### 3.2 美联储反应函数（参数化）

```
政策利率变动 = α·(通胀缺口) + β·(失业率缺口) + γ·(金融条件) + δ·(政治压力) + ε
```

- α、β 由历史泰勒规则估计；γ 用金融条件指数；δ 用白宫公开施压事件的哑变量。
- 每次 FOMC 后，用"声明措辞变化 + 点阵图 + 市场定价（OIS/期货隐含路径）"三者交叉验证。
- 输出：未来 3 次会议的**概率分布**（降息/维持/加息）+ 触发条件（如"若 CPI 环比 > 0.3% 则概率反转"）。

### 3.3 财政部与汇率干预模型

- 发债结构：短债占比上升 → 前端压力、期限溢价变化；长债发行增加 → 长端利率上行压力。
- 汇率干预工具箱：口头、询价（rate check）、联合干预、FIMA repo、远期/掉期。系统记录每次干预的**规模估计、持续时间、市场反应**，并判断"临时手段 vs 结构解决"。
- 案例（用户 2026-08-09 笔记）：美日联合干预日元 → 美元指数短期下行 → 黄金短期受益；但因日本结构性问题（财政、能源、经常账户）未解，日元仍将贬值 → 第二轮干预前是黄金加仓窗口。系统要把这类**条件链**建成可复用模板。

### 3.4 政治日历

- 美国：中期选举（2026-11-03 投票）、FOMC 会议、债务上限、预算、关税节点。
- 中国：政治局会议（4/7/10/12 月）、中央经济工作会议（12 月）、两会（3 月）、LPR 调整。
- 日本：央行会议、财政预算、选举。
- 欧洲：ECB 会议、财政规则。
- 系统在日历事件前 T-7/T-1 自动生成"预期 vs 可能意外"清单，事件后自动记录实际值与市场反应。

## 4. 资产定价逻辑库（Pricing Engine）

### 4.1 统一分解框架

对任意资产，价格变动可分解为：

```
ΔP ≈ 贴现率效应（无风险利率 + 风险溢价）
    + 现金流/供需效应（基本面）
    + 流动性/仓位效应（资金面）
    + 叙事/情绪效应（反身性）
    + 残差（未知/噪音）
```

系统对每个资产维护一个**结构化定价模型**（公式 + 参数 + 数据依赖 + 证据），并用滚动回归/归因给出贡献度。模型不是"预测公式"，而是"解释当前价格在交易什么"的工具。

### 4.2 黄金（核心品种）

```
金价 ≈ f(实际利率, 美元, 央行购金, ETF 流量, 地缘风险, 通胀预期, 仓位拥挤度)
```

| 因子 | 方向 | 观测指标 | 滞后 | 说明 |
|---|---|---|---|---|
| 实际利率（10Y TIPS） | 负 | FRED DFII10 | 同步/领先 1–2 月 | 持有黄金的机会成本 |
| 美元指数 | 负 | DXY | 同步 | 计价效应 + 避险 |
| 央行购金 | 正 | WGC、央行储备 | 慢变量 | 结构性需求，价格不敏感 |
| ETF 持仓 | 正 | GLD/IAU 份额 | 同步 | 金融需求与情绪 |
| 地缘风险 | 正 | 事件库、VIX、油价 | 事件驱动 | 脉冲式 |
| 通胀预期 | 正/不确定 | 5y5y、盈亏平衡 | 同步 | 与实际利率共同作用 |
| 仓位拥挤 | 反转 | COT 净多分位、期权 skew | 1–4 周 | 极端时均值回归 |

**分析输出示例（以用户 2026-08-09 笔记为原型）**：趋势判断（筑底→单边）、价格目标（9–12 月 4800–5000；27 年初破 5600）、短期影响因素（原油弱相关、数据弱相关、美元指数主要、利率次要）、回调加仓逻辑（计价 ADP/非农、二次下杀）、失效条件（实际利率大幅反弹/美元突破）。系统要把这段"人话"转化为：因子贡献表 + 证据链 + 概率情景 + 国内 AU 合约映射。

### 4.3 白银

```
银价 ≈ 金价 × 金银比；金银比 ≈ f(工业需求/风险偏好, 库存, 实际利率)
```
- 金银比 > 90 分位 → 白银补涨概率；< 10 分位 → 白银高估。
- 工业属性：光伏、电子；库存（LBMA/COMEX/上期所）。

### 4.4 原油

```
油价 ≈ 供需平衡（供给 - 需求）+ 库存偏离 + 地缘风险溢价 + 美元 + 裂解价差/月差
```

| 维度 | 指标 | 用法 |
|---|---|---|
| 供给 | OPEC+ 产量与剩余产能、美国页岩产量与钻机数、伊朗/委内瑞拉/俄罗斯出口 | 剩余产能 < 3% 时地缘溢价放大 |
| 需求 | 全球出行、工业产出、中国进口、炼厂开工 | 需求端边际变化定方向 |
| 库存 | OECD 库存、EIA 周度、浮仓 | 库存偏离 5 年均值定强弱 |
| 结构 | 月差（back/contango）、裂解价差、EFP | 月差走强 = 现货紧张 |
| 地缘 | 霍尔木兹、俄乌、中东、制裁 | 事件驱动，脉冲后衰减 |

**区间判断法**（用户笔记风格）：给定供需平衡与地缘溢价，输出"70–90 美元宽幅震荡"式区间，并给出突破条件（如"美元指数大幅下跌"）。

### 4.5 工业金属（铜/铝/锌/镍/锡）

| 品种 | 核心供给逻辑 | 核心需求逻辑 | 关键指标 |
|---|---|---|---|
| 铜 | 矿山品位下降、罢工、TC/RC 低位、新矿投产周期 | 电网、地产、新能源（光伏/风电/EV）、家电 | LME/SHFE/COMEX 库存、保税库存、TC/RC、精废价差、进口盈亏 |
| 铝 | 中国产能天花板 4500 万吨、能耗双控、云南水电 | 地产、汽车轻量化、光伏边框 | 电解铝利润、氧化铝价格、社会库存、铝棒加工费 |
| 锌 | 矿山减产、冶炼利润 | 镀锌（地产/基建） | TC、社会库存、镀锌开工 |
| 镍 | 印尼镍铁/高冰镍、硫酸镍 | 不锈钢、三元电池 | 印尼政策、LME 库存、镍铁价差 |
| 锡 | 缅甸/印尼供给扰动 | 焊料（电子） | 库存低位、半导体周期 |

**铜金比**作为全球增长预期的代理；**铜油比**作为通胀/需求结构参考。

### 4.6 国债与利率

```
名义收益率 = 实际利率 + 通胀预期 + 期限溢价
期限溢价 ≈ f(国债供给, 外国需求, 波动率, 政策不确定性)
```

- 美债：关注拍卖（尾部、投标倍数）、TIC 资金流、外国官方持仓、财政赤字、债务上限、期限溢价（ACM 模型）。
- 中债：政策利率、降准降息、信用扩张、地方债供给、机构行为（农商行/理财）。
- 日债：YCC 退出、财政扩张、日央行购债、寿险需求。
- 全球利差 → 汇率 → 资本流动 → 风险资产；**美日利差是套息交易的核心变量**。

### 4.7 汇率

```
汇率 ≈ f(利差, 贸易/经常账户, 资本流动, 风险偏好, 央行干预, 政治因素)
```

- 美元微笑：全球衰退（避险买美元）与美国独强（利差买美元）两端走强，中间走弱。
- USDJPY：美日利差 + 套息 + 干预；USDCNH：中美利差 + 贸易顺差 + 中间价信号 + 资本管制。
- 干预识别：即期异常成交、掉期、官方表态、央行资产负债表变化。

### 4.8 股票与个股（含洛阳钼业模板）

**指数**：`E/P ≈ 实际利率 + 股权风险溢价 - 盈利增速预期`；关注估值分位、盈利修正广度、流动性、风险偏好。

**有色个股通用模型**：

```
股价 ≈ Σ(金属价格 × 产量 × 权益比例 - 成本) × (1 - 税率) × 估值倍数 / 股本
       + 资源价值（矿山储量重估）
       + 催化（并购、投产、政策）
       - 风险（地缘、环保、汇率、诉讼）
```

**洛阳钼业（603993）分析模板**（深度个股范例）：
1. 业务结构：铜钴（TFM/KFM，刚果金）、钼钨（国内）、铌磷（巴西）、金属贸易（IXM）。
2. 量：铜产量指引与爬坡、钴产量（刚果金出口政策）、钼钨价格。
3. 价：铜价敏感性（每 1000 美元/吨对利润影响）、钴价、汇率（美元/人民币、刚果法郎）。
4. 成本：C1 成本分位、能源、运费、特许权使用费。
5. 估值：PE/PB/EV-EBITDA 分位、资源量重估（NAV）、股息。
6. 催化：KFM 二期、TFM 扩产、钴出口配额、铜价周期、并购。
7. 风险：刚果金政策（矿业法、出口限制）、地缘、铜价下行、汇率、ESG。
8. 交易映射：A 股个股 vs 沪铜期货的对冲/替代关系；AH 溢价（若有）。
9. 证据：公告、财报、产量指引、行业数据、券商一致预期。
10. 输出：目标价区间 + 情景（铜价 9000/10000/11000 美元）+ 概率 + 失效条件。

### 5.2 内置传导链模板（部分）

1. **实际利率 → 黄金**：TIPS 上行 → 持有成本上升 → 金价承压（同步，强度中，危机时减弱）。
2. **日元套息 → 全球流动性**：日元升值 → 套息平仓 → 风险资产抛售（快，尾部强）。
3. **油价 → 通胀预期 → 利率 → 美元 → 黄金**：油价上行 → 通胀预期升 → 加息预期 → 实际利率升 → 金价先跌后涨（取决于央行反应函数）。
4. **美债利率 → 成长股**：长端利率上行 → 贴现率上升 → 高估值成长股承压（久期效应）。
5. **中国信用脉冲 → 铜**：社融/信贷扩张 → 地产基建需求 → 铜价（滞后 1–3 月）。
6. **美元 → 新兴市场**：美元走强 → 资本流出 → EM 股市/汇率承压。
7. **风险开关（Risk-on/off）**：VIX、信用利差、黄金/铜比、日元；切换时多资产同向。
8. **央行购金 → 黄金**：结构性买盘，价格不敏感，压低波动率、抬升中枢。
9. **关税 → 通胀 → 美联储**：关税落地 → 商品价格上升 → 通胀预期 → 降息推迟 → 美元/黄金反应。
10. **财政发债 → 期限溢价 → 长端利率**：短债化 → 前端压力；长债供给 → 期限溢价。
11. **美日干预 → 美元指数 → 黄金**（用户案例）。
12. **AI 资本开支 → 铜/电/半导体**：结构性需求 vs 泡沫破裂风险。

### 5.3 估计与验证

- 滚动相关（60/120/250 日）、DCC-GARCH（条件相关）、Granger 因果（注意伪相关）、转移熵（非线性）。

### 9.2 断言级可信度

```
可信度 = sigmoid( β0
        + β1·来源等级
        + β2·多源印证（独立源数量）
        + β3·具体性（有数字/时间/原文）
        + β4·时效性
        - β5·利益冲突
        - β6·历史错误率 )
```

- 权重由历史校准（来源准确率 = Brier 分数转换）。
- 冲突：同一事实多源矛盾时，保留全部断言，取最高可信度为"当前最佳"，并标注分歧。

### 9.3 贝叶斯更新

```
P(假设 | 新证据) ∝ P(新证据 | 假设) · P(假设)
```

- 每个论点（thesis）维护先验概率；新证据到来时更新后验，并记录更新日志。
- 证据的似然比由证据类型与可信度决定（规则表，可人工调整）。
- 输出：概率变化 + 触发原因 + 是否需要调整交易计划。

### 9.4 防幻觉与事实校验（硬约束）

1. **引用强制**：任何结论必须挂 claim_id；无证据 → 标记"假设/推断"。
2. **数字双校验**：LLM 引用的数字必须与结构化数据源匹配（容差 0.1%），否则拒绝入库。
3. **多模型交叉**：关键结论由第二模型（或规则）复核，分歧大时降置信度并标记人工复核。
4. **反身性提示**：区分"事实"与"市场叙事"；叙事本身可交易，但必须标注。
5. **人工闸门**：涉及金额/方向/仓位的计划必须人工确认后才进入"已执行"。

## 10. 交易系统（EPIC-T）

### 10.1 设计理念（与用户笔记一致）

- 交易是概率游戏，追求长期正期望与复利。
- 盈亏比优先于胜率；预期盈亏比 ≥ 3:1 才参与；胜率 ≥ 25%（由盈亏比反推）。
- 防守优先：先想亏多少，再想赚多少；单笔风险 0.2%–0.3%（可配 0.5%），总仓位 ≤ 50%，现金/存款 ≥ 50%。
- 只做"看得懂"的机会（1% 的行情），其余时间空仓等待。
- 严格止损：价格、时间、次数三条止损线，触发任一即离场。
- 分批建仓：8%/4%/2%/1% 原则（用户笔记）。
- 不做预测式左侧交易，等突破确认（翟鹏飞体系）；基本面定方向，技术面定时点。

### 10.2 信号层（五类）

| 信号 | 规则（示例） | 适用 | 失效 |
|---|---|---|---|
| 趋势突破 | 突破 20/60 日高低点 + 放量 + 持仓增 | 单边市 | 震荡市假突破 |
| 动量 | 60 日动量分位 + 均线多头排列 | 趋势延续 | 动量衰竭 |
| 均值回归 | 偏离 200 日均线 2σ + 情绪极端 | 震荡市 | 趋势加速 |
| 跨市套利 | 沪伦比偏离进口盈亏平衡 ±2σ | 内外盘 | 汇率/关税突变 |
| 事件驱动 | 事件冲击方向 + 历史窗口统计 + 仓位 | 数据/政策 | 事件已被计价 |

**入场三重确认**：逻辑（基本面/宏观）+ 结构（支撑阻力/趋势）+ 时机（突破/回调确认 + 时间窗口）。

### 10.3 仓位引擎

```
单笔风险金额 = 总资金 × 风险比例（默认 0.25%）
开仓手数 = 单笔风险金额 ÷ (止损点数 × 每点价值)
Kelly 上限 = (p·b - q) / b；实际使用 min(半 Kelly, 单品种上限, 总仓位约束)
```

- 相关性调整：同向多品种（铜/铝/油）合并风险敞口 ≤ 0.6%。
- 波动率调整：按 ATR 缩放，避免高波动期仓位过大。
- 极端行情：VIX 分位 > 90% 时仓位减半。

### 10.4 止损与离场

| 类型 | 规则 |
|---|---|
| 价格止损 | 逻辑位（前低/突破启动线）外 0.5–1 ATR；或固定金额止损 |
| 时间止损 | 入场后 1/3 周期（日线第 3 根 K 线）收盘未脱离成本区 → 离场 |
| 次数止损 | 当日止损 3 次 → 停止交易，复盘 |
| 移动止盈 | 保本 → 利润 50% 后跟踪止损（回撤 20–30% 利润） |
| 目标止盈 | T1 减半仓，T2 跟踪；不设死目标，让利润奔跑 |

### 10.5 国内执行映射（关键约束）

外盘信号必须落到国内可交易标的：

| 外盘信号 | 国内标的 | 映射要点 |
|---|---|---|
| COMEX 黄金 | 沪金 AU | 汇率、内外价差、保证金、夜盘至 02:30 |
| COMEX 白银 | 沪银 AG | 波动更大，仓位折半 |
| WTI/Brent | INE 原油 SC | 汇率、仓单、交割规则、夜盘 |
| LME 铜 | 沪铜 CU | 沪伦比、进口盈亏、保税库存 |
| LME 铝/锌/镍 | 沪铝/沪锌/沪镍 | 内外价差、库存、出口窗口 |
| SGX 铁矿 | DCE 铁矿 I | 品位、基差、限仓 |
| CBOT 大豆/玉米 | DCE 豆粕/豆油/玉米 | 压榨利润、进口成本、汇率 |
| 美股有色/金矿 | A 股有色个股 | Beta、汇率、估值差；洛阳钼业为模板 |

执行细节：合约选择（主力/次主力）、涨跌停与保证金、手续费与滑点、交割月限仓、夜盘与假期、汇率换算、税务（增值税/关税）。

### 10.6 回测与评估

- 指标：胜率、盈亏比、期望值、最大回撤、夏普、Calmar、时间止损触发率、信号衰减。
- 方法：walk-forward、样本外验证、交易成本（手续费+滑点+冲击）、避免未来函数。
- 归因：按信号类型/品种/regime 拆分收益来源。
- 预测登记：每条观点记录概率、时点、到期日；Brier 分数、校准曲线、分资产命中率。

### 10.7 交易心理与纪律（系统化）

- 计划外交易：系统记录并标红（"违规交易"），周报复盘。
- 连亏熔断：连续 3 次止损或日亏 3% → 强制冷却 1 个交易日。
- 情绪记录：下单时打标签（FOMO/恐惧/纪律），与结果相关性分析。

## 11. 分析 SOP（每日执行流程）

### 盘前（07:30–08:30）

1. 数据完整性检查（行情、宏观、新闻）。
2. 隔夜事件流：按资产/影响排序，读 Top-10。
3. 周期与政策状态：是否有变化（FOMC、讲话、数据）。
4. 跨市场验证：美债/美元/黄金/铜/油是否同向；背离清单。
5. 持仓与资金流：COT、ETF、SHFE 排名变化。
6. 生成简报：主线 + 分资产 + 日程 + 计划摘要。
7. 人工修订 15 分钟，保存版本。

### 盘中（按需）

1. 异动告警 → 查新闻 → 判断"信息驱动 vs 流动性驱动"。
2. 检查论点/失效条件是否触发。
3. 记录人工判断。

### 盘后（21:00–22:00）

1. 当日复盘：主线是否兑现，背离是否收敛。
2. 计划执行对账。
3. 预测登记。
4. 生成盘后简报 + 明日日程。

### 周末（2–3 小时）

1. 周期定位复核（月度/季度数据）。
2. 历史类比更新。
3. 个股深度（每周 1 只，洛阳钼业优先）。
4. 系统复盘：命中率、信号、模型参数。
