## 2. 核心功能规格（逐条）

### F1 晨报

| 项 | 内容 |
|---|---|
| 用户故事 | 开盘前 5 分钟读完，知道「今天最重要的一件事 + 当下周期 + 四个情景」 |
| 结构 | ① 一句话结论（带置信度）② 关键变化 5 条（附 z 分数）③ 今日日历（importance≥2）④ 预警 3 条 ⑤ 情景与概率 ⑥ 失效触发器 |
| 数据 | `briefs` + `derivations` + `economic_events` + `alerts` + `cycle_states` |
| 交互 | 每段可展开「依据」；顶部显示 `RUN-…` 与 `数据时点`；可导出 Markdown/PDF + 审计包 |
| 验收 | 任一结论点击 ≤3 次可看到贡献分解与反对证据；未复核时显示徽标 |

### F5 周期罗盘

| 项 | 内容 |
|---|---|
| 用户故事 | 一眼看到「我在五层周期的哪个位置，哪一层最危险」 |
| 结构 | 中心罗盘（五圈同心：政治/信用/库存/短债务/长债务）+ 右侧大周期六阶段进度条 + 底部三指数雷达（DMI/ICI/ECI） |
| 交互 | 点任一圈 → 展开该层判定依据、贡献分解、失效条件；切换国家下拉；时间滑块回看历史定位 |
| 数据 | `cycle_states`、`derivations`、`power_index` |
| 验收 | 每层至少 3 个可观测依据 + 1 个失效条件；历史滑块可看到过去 24 个月阶段变化 |

### F7 历史类比

| 项 | 内容 |
|---|---|
| 用户故事 | 「现在最像哪几年？那之后发生了什么？」 |
| 结构 | 状态向量热力条 + Top-5 类比卡（年份/相似度/后续 12 个月 GDP·CPI·股指·黄金）+ 分布箱线图 |
| 交互 | 点击类比年份 → 跳转长河时间轴对应位置；可调相似度阈值 |
| 验收 | 必须显示 `n_cases` 与样本时代提示（金本位/浮动汇率） |

### F9 时间轴（世界长河）

| 项 | 内容 |
|---|---|
| 用户故事 | 把 500 年压成一屏，理解「大国兴衰与货币更替的节奏」 |
| 结构 | 主时间轴（1500–2026）+ 多层泳道（经济/货币/战争/制度/技术）+ 实力面积图（6 国）+ 周期带 |
| 交互 | 播放/暂停/倍速；缩放（世纪→十年）；点击事件弹出卡片（影响 + 来源 + 当时的资产表现）；可叠加「周期带」层 |
| 验收 | 24 个关键节点全部可点；播放 60 秒走完 500 年；任意事件有来源链接 |

### F20 推导谱系（为什么抽屉）

| 项 | 内容 |
|---|---|
| 用户故事 | 「这个 73% 是怎么来的？」 |
| 结构 | 5 层折叠：结论 → 贡献瀑布 → 规则命中 → 特征值 → 原始观测；右侧反证区 |
| 交互 | 每次展开懒加载；数值 hover 显示 `derivation_id`；底部「导出这一段推理」 |
| 验收 | 见 [19 §10](./19-透明化业务流程设计.md) T1–T10 |

### F21 反事实沙盘

| 项 | 内容 |
|---|---|
| 用户故事 | 「如果实际利率降 100bp，结论会变吗？」 |
| 结构 | 3–6 个滑块（实际利率、金价、DXY、赤字率、油价、央行购金）+ 实时结论强度条 + 「翻转阈值」提示 |
| 交互 | 拖动即算（前端调 `/counterfactual`，<300ms）；重置按钮；保存为情景 |
| 验收 | 任一次拖动返回贡献变化与是否翻转；保存后进入 `scenarios` 表 |

### F24 预测台账

| 项 | 内容 |
|---|---|
| 用户故事 | 「我过去一年到底准不准？比瞎猜强多少？」 |
| 结构 | 预测列表（对象/期限/方向/概率/状态）+ 校准曲线 + Brier 分解 + 按品类/期限分组 |
| 交互 | 手动登记（可关联 derivation）；到期自动结算；失败预测必须填归因 |
| 验收 | 到期 100% 结算；Brier 与基准率并列；每月自动生成复盘报告 |

### F31 数据源健康

| 项 | 内容 |
|---|---|
| 用户故事 | 「哪些数据在拖后腿？」 |
| 结构 | 源卡片（成功率、P95 延迟、最近失败、降级链）+ 任务甘特（近 24h）+ 覆盖率热力 |
| 交互 | 点源 → 最近 20 次抓取详情（URL/状态/字节/耗时）；手动重试 |
| 验收 | 任一失败可看到具体错误与影响的下游结论 |

## 3. 接口设计规范

### 3.1 统一响应

```json
{
  "items": [],
  "total": 0,
  "asof": "2026-11-17",
  "run_id": "RUN-20261117-1610",
  "degraded": false,
  "degraded_reasons": [],
  "generated_at": "2026-11-17T16:12:03+08:00"
}
```

- 单对象也包成 `{"item": {...}}`，便于未来加元数据；
- 所有时间带时区（`+08:00`）；
- 数值统一 `number`，比率用小数（0.0512）而非百分数，单位字段另给；
- 缺失用 `null`，不用 `0` 或 `""`；
- 每个响应带 `degraded`，前端顶栏据此显示降级徽标。

### 3.2 错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | `invalid_param` | 参数非法（附 `field`） |
| 404 | `not_found` | 实体不存在 |
| 409 | `conflict` | 版本冲突（乐观锁） |
| 422 | `unprocessable` | 语义错误（如区间不合法） |
| 429 | `rate_limited` | 限流（附 `retry_after`） |
| 503 | `data_degraded` | 数据不可用（附降级原因） |
| 500 | `internal` | 附 `trace_id` |

### 3.3 分页与筛选

```
GET /api/forecasts?status=active&horizon=3m&page=1&size=50&sort=-created_at
```

- `page` 从 1 开始，`size` 默认 50、上限 200；
- `sort` 支持 `field` / `-field`；
- 时间范围统一 `from`/`to`（ISO 日期）。

### 3.4 通用参数

| 参数 | 说明 |
|---|---|
| `asof` | 数据时点（时点回放），默认最新 |
| `vintage` | `latest` / `as_of_original` |
| `window` | `1d/5d/1m/3m/6m/1y/5y/10y/max` |
| `country` | ISO2，多值逗号分隔 |
| `legacy` | `true` 时返回 V1.3 结构（兼容） |

## 7. 非功能要求

| 项 | 要求 |
|---|---|
| 首屏 | 本地 < 800ms；交互响应 < 100ms；反事实 < 300ms |
| 可用性 | 键盘可达；对比度 ≥ 4.5:1；所有图表有表格替代视图 |
| 数据量 | 单页最多 5000 点，超出降采样（LTTB） |
| 缓存 | 分析结果按 `(method, asof)` 缓存；ETag 支持 |
| 安全 | 仅本机 127.0.0.1；导出包默认脱敏（不含 token） |
| 可观测 | 每个请求记录 `trace_id`、耗时、`degraded` |
| 兼容 | 旧 API 保持可用至少一个大版本（过渡期 `/legacy` 看板已于 V1.3 收尾时删除） |
