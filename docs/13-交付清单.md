## 3. 使用方式（最短路径）

```powershell
cd D:\Code\4_个人研发\economic-analysis-tool
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1   # 首次
powershell -File .\scripts\start.ps1
# 打开 http://127.0.0.1:8765
powershell -ExecutionPolicy Bypass -File .\scripts\selfcheck.ps1
```

## 5. 已知限制（诚实清单）

1. **LLM 全链路未用真实 Key 实跑**（代码/测试/回退就绪）。
2. **M6 两周试运行未完成**（需真实使用）。
3. 美国财政部新闻源失效（已用 USTR 替代）；大商所持仓为新浪页面抓取（S2），非交易所官方。
4. 市场隐含周期置信度 0.35–0.40；历史类比与事件研究样本有限。
5. 回测为日线简化模型，不含完整滑点/保证金占用；不构成收益预期。
6. 事件→方向、持仓背离等为规则启发式，需人工核实。
7. 自动交易明确不做（V1 边界）。
