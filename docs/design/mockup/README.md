# EPIC · 新前端 UI 静态原型

面向「本地个人宏观—市场—交易分析工作台」的 UI 改造方向确认稿。纯静态单文件，**离线可打开，无任何外部字体 / CDN / 图片依赖**；所有图标为内联 SVG，迷你走势与图表由原生 JS 生成内联 SVG。

- 深色为默认主题（专业金融终端），浅色主题可切换，两套均完整可用。
- 界面文字为简体中文，数值带单位或百分比，时间显示到分钟，行情时点为北京时间。
- 原型以 1440×1000 桌面视口为基准，窄屏（≤1240 / ≤1024）提供兜底布局。

## 2. 如何打开

### 方式 A：本地 HTTP（推荐，截图同款）

```powershell
Set-Location 'D:\Code\4_个人研发\economic-analysis-tool'
& '.\.venv\Scripts\python.exe' -m http.server 8899 --bind 127.0.0.1 --directory 'docs\design\mockup'
```

浏览器访问：

- <http://127.0.0.1:8899/?view=overview>（默认深色总览）
- <http://127.0.0.1:8899/?view=market>
- <http://127.0.0.1:8899/?view=brief>
- <http://127.0.0.1:8899/?view=tokens>
- <http://127.0.0.1:8899/?view=overview&theme=light>（浅色）

### 方式 B：直接双击 `index.html`

也可离线打开；但部分浏览器在 `file://` 下对 `history.replaceState` / 剪贴板有限制，原型的相关调用均已做容错，视图切换仍可用。建议优先用方式 A。

## 3. URL 参数与视图

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `view` | `overview` / `market` / `brief` / `tokens` | 初始视图；侧边栏点击与命令面板会同步更新 URL |
| `theme` | `dark` / `light` | 临时覆盖主题（不写入 localStorage），便于分享与截图 |
| `open` | `evidence` / `settings` / `palette` / `toast` | 深链直接打开证据抽屉 / 设置抽屉 / 命令面板 / 示例 Toast |
| `debug` | `1` | 开发自检：把页面尺寸、横向溢出元素、关键区块坐标写入 `document.title` |

也支持初始 `#overview`、`#market` 等哈希写法；主题与外观偏好保存在本机 `localStorage`（键名 `epic-prefs`），**localStorage 为空时始终默认深色**。

## 4. 已实现交互

### 全局 / 导航

- 左侧 232px 固定侧边栏：4 个可用视图 + 15 个后续模块入口；未接入模块点击给出 Toast 提示，不跳空白页。
- 顶栏 56px 吸顶：面包屑、全局搜索入口（命令面板）、数据同步状态、告警入口、主题切换、设置抽屉、账户头像。
- 视图切换同时支持侧边栏、命令面板与 `?view=` / `#view`；切换后自动回到页首。
- 主题切换（顶栏月亮/太阳按钮、设置抽屉、设计规范页按钮）：深色 ↔ 浅色，双主题完整适配，偏好持久化。
- 涨跌配色切换（设置抽屉）：默认**红涨绿跌**，可切为绿涨红跌；所有涨跌色通过 `--up-color / --down-color` 统一生效。
- 界面密度切换（标准 / 紧凑），影响表格行高与卡片间距。
- Toast 通知：复制、刷新、导出、切换等操作均有轻量反馈，2.6 秒自动消失。

### 命令面板（Ctrl+K / ⌘K / `/`）

- 顶栏搜索框或键盘快捷键打开；输入即筛选（页面名 + 关键词 + 操作）。
- `↑` / `↓` 选择、`Enter` 执行、`Esc` 关闭；鼠标可点击。
- 可执行：切换 4 个视图、切换主题、打开设置、查看证据 E-01、打印简报、复制摘要、导出行情 CSV。

### 证据抽屉（右侧 480px 滑出）

## 5. 重新生成截图

要求 Chrome 已安装。**注意**：在这台机器上 `chrome.exe` 命令行会先返回、后写文件，直接调用会读不到 PNG；请用 `Start-Process -Wait`，并给每次运行独立的临时 profile。

```powershell
Set-Location 'D:\Code\4_个人研发\economic-analysis-tool'
$chrome = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
$dir    = 'D:\Code\4_个人研发\economic-analysis-tool\docs\design\mockup'

# 1) 先起本地 HTTP 服务（另开一个终端，保持运行）
& '.\.venv\Scripts\python.exe' -m http.server 8899 --bind 127.0.0.1 --directory 'docs\design\mockup'

# 2) 逐张截图（每个视图一个独立临时 profile，避免缓存与主题偏好串台）
$jobs = @(
  @{ name = 'overview';       url = 'http://127.0.0.1:8899/?view=overview' },
  @{ name = 'market';         url = 'http://127.0.0.1:8899/?view=market&theme=dark' },
  @{ name = 'brief';          url = 'http://127.0.0.1:8899/?view=brief&theme=dark' },
  @{ name = 'tokens';         url = 'http://127.0.0.1:8899/?view=tokens&theme=dark' },
  @{ name = 'overview-light'; url = 'http://127.0.0.1:8899/?view=overview&theme=light' }
)
foreach ($job in $jobs) {
  $png = Join-Path $dir "preview-$($job.name).png"
  $prof = Join-Path $env:TEMP "epic-chrome-$($job.name)-$(Get-Random)"
  $args = @(
    '--headless=new','--disable-gpu','--disable-extensions','--hide-scrollbars',
    '--force-device-scale-factor=1',
    "--user-data-dir=$prof",'--window-size=1440,1000','--virtual-time-budget=4000',
    "--screenshot=$png",$job.url
  )
  $p = Start-Process -FilePath $chrome -ArgumentList $args -Wait -PassThru -WindowStyle Hidden
  Start-Sleep -Milliseconds 350
  Write-Output "$($job.name): exit=$($p.ExitCode), bytes=$((Get-Item $png).Length)"
}
```

截图参数说明：

- `1440,1000`：与验收一致的桌面视口；`--force-device-scale-factor=1` 保证 1x；
- `--hide-scrollbars`：隐藏滚动条，同时页面布局仍为 1418px 内容宽度（Chrome 预留 22px 滚动条槽，属正常现象，无横向滚动）；
- `--virtual-time-budget=4000`：给 JS 渲染与动画留时间；固定基准时钟保证每张图时间一致（17:32:0x）；
- 每个视图用新 profile，避免 localStorage 中的主题偏好影响「深色默认」的验收。

## 9. 已知限制 / 开放问题

1. **非 Vue 实现**：本稿仅用于确认视觉与交互方向；分析引擎、交易信号、持仓结构等 15 个入口未接入，点击以 Toast 说明。
2. **数据为示例**：原型不请求 FastAPI（`127.0.0.1:8765`），刷新仅更新提示与时钟；真实数据接入后需补充加载态、错误态与空态分支。
3. **打印 / PDF** 依赖浏览器打印对话框（「另存为 PDF」）；未内置 PDF 生成库（保持零依赖）。
4. **时钟**使用固定基准时间便于截图复现；Vue 版应改用后端时间 / 本地真实时间，并处理休市日。
5. **响应式**仅做桌面优先的兜底布局；移动端需单独设计（表格横向滚动 / 卡片堆叠）。
6. **字体差异**：截图使用本机 system-ui 字体（Windows 的 Segoe UI / Microsoft YaHei），不同系统字宽可能导致 1–2px 差异。
7. 设计规范页内容较长，1440×1000 首屏展示色板 / 字阶 / 按钮 / 间距 / 卡片与表单开头，其余组件需向下滚动查看。
