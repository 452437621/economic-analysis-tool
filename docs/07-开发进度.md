## 2026-11-09 · M3 分析引擎 v0（基础完成）

### 已实现

- **指标引擎**（14 个品种）：1/5/20/60 日涨跌、MA20/60 偏离、20 日年化波动、252 日分位、趋势状态、持仓 5 日变化。
- **市场隐含周期**（美/中）：增长/通胀/流动性打分（0–100）+ 四象限（复苏/过热/滞胀/衰退/过渡），附方法说明与置信度（0.35–0.4）。美：曲线斜率 + 铜金比 + 盈亏平衡 + 油价 + 实际利率；中：铜/铁矿/股指 + 油/豆粕/棕油。
- **定价归因**：AU/AG/CU/SC/603993/000300 对「美国实际利率变化、盈亏平衡变化、曲线变化」做 120 日 OLS，输出 beta、近 20 日贡献、残差与 R²。
- **跨资产相关性**：14 品种 120 日收益相关矩阵、平均 |ρ|、最强联动对（当前 AG/AU 0.858，平均 |ρ| 0.33）。
- **市场风向**：广度 + 20 日动量 + 10Y 利率变化合成 -100~100 分（当前避险 -54.7）。
- **历史类比**：8 维周频状态向量（利率水平/实际利率/盈亏平衡/曲线/黄金/铜/油/股指动量），Top5 相似时段 + 未来 20/60 日收益，附样本与失效提示。
- **API**：`/api/analytics/overview|wind|regimes|indicators|attribution|correlation|analogs`。
- **看板**：分析引擎区（风向卡、中美周期卡、相关性卡、归因表、历史类比表）。
- **任务**：`analyze` 每日 16:10 + 启动回补；当前结果 asof 2026-11-06。
- **测试**：新增 M3 单测 6 条（指标、象限、归因 beta 恢复、相关性、风向区间、类比），总计 **22 条全部通过**。

### 已实现

- **API**：`/api/market/snapshot`、`/api/market/bars`、`/api/macro/latest`、`/api/macro/series`、`/api/news`、`/api/system/sources`。
- **看板**：市场快照分组表（贵金属/能源/黑色/农产品/汇率/股指）、利率卡、新闻流、数据源健康、任务状态；延迟/旧数据徽标。
- **数据量（首次回补后）**：28 个标的、27,804 根日线、9,696 条利率观测、35 条新闻、5 个数据源。
- **测试**：解析器离线测试 9 条（新浪日线/国内快照/外盘/汇率、东财行情/K线、财政部曲线、RSS、DXY 合成）+ smoke 4 条，全部通过。

### 遇到的问题与修复

| 问题 | 根因 | 处理 |
|---|---|---|
| 批量 UPSERT 报 `unable to open database file` (SQLITE_CANTOPEN) | 多行 UPSERT 触发 SQLite 临时文件；本机环境临时目录/文件句柄偶发不可用 | 连接级 `PRAGMA temp_store=MEMORY`；UPSERT 增加瞬时错误重试（幂等）；已验证稳定 |
| 沪深300 被写成 `192` | YAML 把未加引号的 `000300` 解析为整数 | 配置中给代码加引号，删除脏数据 |
| 玉米/豆粕等品种无数据 | 配置重写时漏掉农产品/黑色品种 | 补充 M/P/SR/CF/I 到配置，已回补 |
| 外盘/美债延迟与口径 | 免费源限制 | 界面徽标标注延迟；美债用官方 CSV；DXY 用代理算法并在名称标注 |
| 采集任务日志噪音大 | 异常打印完整 SQL | 后续统一日志级别与错误摘要（M1 收尾） |

### 与文档的偏差
