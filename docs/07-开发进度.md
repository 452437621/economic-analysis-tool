## 2026-11-09 · M0 环境与骨架（完成）

### 已完成

- **工作区修复**：DSH 工作区 Windows ACL 异常（`SetNamedSecurityInfoW` 失败），按诊断脚本修复并验证；备份/回滚文件在 `..\economic-analysis-tool-acl-recovery\`。
- **Python 运行时**：系统 Python 3.8.10 过旧（akshare 新版要求 ≥3.11）。通过 uv 在工作区内安装 **Python 3.12.16**（`.python/`），不修改系统环境；uv 位于 `.tools/uv/bin/uv.exe`（被 gitignore）。
- **依赖**：`.venv` 安装 FastAPI 0.162、SQLAlchemy 2.1、APScheduler 3.x、pandas、duckdb、pytest 等。
- **配置**：`config/default.yaml`（关注清单 22 个标的、LLM、调度）；`.env.example`；`.env` 不提交。
- **数据库**：SQLite（WAL）建库，24 张核心表（行情/宏观/文档/断言/事件/论点/情景/信号/计划/预测/任务/LLM 调用/审计/传导边等），见 `backend/app/models/core.py`。
- **调度器**：APScheduler 心跳任务（60 秒）运行，任务状态入 `jobs` 表。
- **API**：`/api/system/health`、`/jobs`、`/job-runs`、`/meta`；`/healthz`。
- **看板**：`web/index.html`（零构建，深色终端风），展示系统/数据库/调度状态、建设进度、任务表；15 秒自动刷新。
- **脚本**：`scripts/setup.ps1`（自动引导 3.12 → venv → 依赖 → 建库）、`start.ps1`（uvicorn，支持 `-Reload`）、`backup.ps1`。
- **测试**：4 条 smoke 测试通过（health / meta 无密钥 / 根页面 / jobs）。
- **验证**：服务启动于 `127.0.0.1:8765`，health 返回 `status=ok`、22 个种子合约、调度器 running。

### 遇到的环境问题

| 问题 | 处理 |
|---|---|
| Windows 工作区 ACL 拒绝写 | 运行诊断脚本修复（已加 FullControl ACE） |
| 系统 Python 3.8 无法装新库 | uv 安装工作区级 Python 3.12.16 |
| pwsh/curl 的 TLS 报 `SEC_E_NO_CREDENTIALS` | 改用 Python 的 SSL 栈下载（已验证通） |

| Chrome 无头截图被沙箱拦截 | 跳过自动截图，用户直接浏览器访问 |
