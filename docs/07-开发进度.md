### 已实现

- **采集适配层**：`Provider` 拆分（sina/eastmoney/treasury/rss）、统一 HTTP 客户端（UA/限速/重试/超时）、原始报文快照落盘（`data/raw/`）、来源健康记录。
- **存储**：新增 `quotes` 表；`market_bars` / `macro_obs` / `documents` 幂等 UPSERT；行情快照保留 14 天。
- **任务编排**：`python -m app.jobs.runner --job/--all`；APScheduler 注册 collect_quotes（5 分钟）、collect_news（3 分钟）、collect_rates（6 小时）、日线（启动回补 + 每日 15:40/06:30）。
- **API**：`/api/market/snapshot`、`/api/market/bars`、`/api/macro/latest`、`/api/macro/series`、`/api/news`、`/api/system/sources`。
- **看板**：市场快照分组表（贵金属/能源/黑色/农产品/汇率/股指）、利率卡、新闻流、数据源健康、任务状态；延迟/旧数据徽标。
- **数据量（首次回补后）**：28 个标的、27,804 根日线、9,696 条利率观测、35 条新闻、5 个数据源。
- **测试**：解析器离线测试 9 条（新浪日线/国内快照/外盘/汇率、东财行情/K线、财政部曲线、RSS、DXY 合成）+ smoke 4 条，全部通过。

### 遇到的问题与修复

| 问题 | 根因 | 处理 |
|---|---|---|
| 批量 UPSERT 报 `unable to open database file` (SQLITE_CANTOPEN) | 多行 UPSERT 触发 SQLite 临时文件；本机环境临时目录/文件句柄偶发不可用 | 连接级 `PRAGMA temp_store=MEMORY`；UPSERT 增加瞬时错误重试（幂等）；已验证稳定 |
| 沪深300 被写成 `192` | YAML 把未加引号的 `000300` 解析为整数 | 配置中给代码加引号，删除脏数据 |
| 玉米/豆粕等品种无数据 | 配置重写时漏掉农产品/黑色品种 | 补充 M/P/SR/CF/I 到配置，已回补 |
| 外盘/美债延迟与口径 | 免费源限制 | 界面徽标标注延迟；美债用官方 CSV；DXY 用代理算法并在名称标注 |
| 采集任务日志噪音大 | 异常打印完整 SQL | 后续统一日志级别与错误摘要（M1 收尾） |
