# 08 使用手册

> EPIC · 个人市场分析工具 ｜ 版本 V3.0.0 ｜ 2026-11-21
> 适用：Windows 10/11、Linux（bash）；个人研究用途。

## 1. 安装

```powershell
# Windows PowerShell（在项目根目录）
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

```bat
:: Windows cmd
scripts\setup.cmd
```

```bash
# Linux / macOS
./scripts/setup.sh
```

也可直接用通用入口：`python scripts/epic.py setup`。

脚本会：

1. 查找 Python 3.12；找不到则用 uv 在工作区 `.python/` 安装（不修改系统 Python）；
2. 创建 `.venv` 并安装依赖（FastAPI、SQLAlchemy、pandas、duckdb、beautifulsoup4 等）；
3. 初始化 SQLite 数据库、写入 28 个标的与任务定义。

首次安装约 2–5 分钟（依赖网络）。

## 2. 启动与停止（三平台一键脚本）

```powershell
# Windows PowerShell
.\scripts\start.ps1                  # 后台启动（默认，自动打开浏览器）
.\scripts\start.ps1 -Foreground      # 前台运行，Ctrl+C 停止
.\scripts\start.ps1 -Reload          # 前台热重载
.\scripts\start.ps1 -Port 8766       # 指定端口
.\scripts\start.ps1 -NoBrowser       # 不打开浏览器
.\scripts\stop.ps1                   # 停止
.\scripts\stop.ps1 -Force            # 强制停止（确认是本项目时）
.\scripts\restart.ps1                # 重启
.\scripts\status.ps1 -Json           # 状态
```

```bat
:: Windows cmd（参数用 --long-form）
scripts\start.cmd
scripts\start.cmd --foreground
scripts\start.cmd --port 8766 --no-browser
scripts\stop.cmd --force
scripts\restart.cmd
scripts\status.cmd --json
```

```bash
# Linux / macOS
./scripts/start.sh
./scripts/start.sh --foreground
./scripts/start.sh --port 8766 --no-browser
./scripts/stop.sh --force
./scripts/restart.sh
./scripts/status.sh --json
```

三套入口都由 `scripts/epic.py` 实现，行为一致。

行为说明：

- **幂等**：已在运行时再次 `start` 只提示，不会起第二个实例。
- **端口保护**：端口被其他程序占用时拒绝启动并打印占用进程，不会误杀。
- **就绪判定**：`/healthz` 返回 200 且端口归属在本次启动的进程树内（venv 的 `python.exe` 是启动器，真实服务是其子进程）。
- **后台脱离**：Windows 用 `DETACHED_PROCESS`，Linux 用 `start_new_session`；启动脚本立即返回，日志写入 `data/logs/server.{out,err}.log`。
- **PID 文件**：`data/run/epic.pid`（含启动器 `pid` 与真实服务 `server_pid`）；停止后自动清理，失效时自动忽略。
- **停止逻辑**：优先停真实服务进程，其次按端口兜底；终止前校验命令行属于本项目（`app.serve` 或 `app.main:app`）。
- **编码**：`.ps1` 为 UTF-8 BOM（PowerShell 5.1 兼容）；`.cmd` 为 ASCII + `chcp 65001`；`.sh` 为 LF。

- 地址：**http://127.0.0.1:8765**
- 备份：`python scripts/epic.py backup`（或 `backup.ps1` / `backup.cmd` / `backup.sh`）→ `data/backup/<时间戳>/`（含 `epic.db` 与 `default.yaml`，自动做 `PRAGMA integrity_check`，保留最近 14 份）
- 恢复：先停止服务，再执行 `python scripts/epic.py restore`（默认取最新备份，恢复前会先做完整性校验并把当前库复制到 `data/backup/pre-restore-<时间戳>/`；`--dry-run` 只校验；`--backup-dir <路径>` 指定备份）
- 测试：`./.venv/Scripts/python.exe -m pytest -q`（Windows）或 `./.venv/bin/python -m pytest -q`（Linux）

启动后 30 秒内自动回补行情、利率、新闻；之后按调度持续更新。

## 3. 每日使用流程

### 盘前 07:30–08:30

1. 打开看板，先看**告警**（价格异动、数据陈旧、风控拦截）。
2. 看「每日简报」（07:30 自动生成）：主线、市场快照 Top5、美债利率、官方新闻、数据缺口。
3. 看「分析引擎」：市场风向、美国/中国周期（市场隐含）、相关性、归因、历史类比。
4. 看「交易信号与计划」：当前信号、草稿计划、风控状态（手数/保证金/手续费）。
5. 点击新闻 → 证据链弹窗：正文高亮数字断言，确认信息源。

### 盘中

- 告警区 30 秒刷新；点击「确认」消除。
- 关注数据质检（CZCE 对账、新鲜度）是否失败。

### 盘后 15:40–17:00

- 15:40 日线更新；15:50 数据质检；16:10 分析引擎重算；16:30 信号/计划重算；17:00 预测对账；21:00 盘后简报。

### 周末

- 复查周期定位、历史类比、事件研究；调整 `config/default.yaml` 关注清单。

## 8. 已知限制

- 无 DeepSeek API Key：断言为规则抽取、简报为模板生成，尚无 LLM 观点/事件抽取与反驳核查。
- 外盘为新浪延迟约 15 分钟；CFTC/LME/Yahoo 国内直连 403；SPDR 历史数据为图片型 PDF。
- 官方宏观（CPI/非农/PMI）未接入（BLS 403），周期为「市场隐含」。
- 回测未含完整交易成本模型（以 0.06% 近似）、未做 walk-forward 组合优化。
- 计划为草稿；不自动下单；实际保证金/手续费以期货公司为准。
- 告警仅站内，邮件/企业微信/Server 酱待接入。

## 9. 排障

| 现象 | 处理 |
|---|---|
| 端口被占用 | 结束占用 8765 的进程，或修改 `.env` 的 `EPIC_PORT` |
| 数据不更新 | 看「任务」最近状态；运行 `--job collect_quotes` 手动触发；看 `data/logs/app.log` |
| 数据库锁 | 等待重试（内置 4 次退避）；避免同时跑多个重任务 |
| 页面空白 | 确认服务运行；浏览器强刷；看 `/api/system/health` |
| 安装失败 | 检查网络；手动安装 Python 3.12 后重跑 setup |

## 12. 重点关注（自选）

- 位置：看板「重点关注」区；默认自选来自 `config/default.yaml` 的 `market.watchlist`（含洛阳钼业）。
- 添加：选择标的 → 填分组 → 选优先级（1 最高）→「添加自选」。
- 移除：卡片右上角 ×，或 `DELETE /api/watchlist/{symbol}`。
- 排序：卡片右上角 **↑ / ↓** 与相邻标的交换位置，顺序会持久化并同步到简报。
- 拖拽排序：默认锁定；点「调整顺序」进入编辑模式，拖动卡片到目标位置，点「保存顺序」生效；「取消」放弃修改。
- 展示：最新价、当日涨跌、20 日变化、分组、备注；简报中也会出现「重点关注（自选）」小节。
- 数据：`GET /api/watchlist`、`GET /api/watchlist/candidates`。
- 分析范围：默认全市场；在 `.env` 设 `EPIC_WATCHLIST_ONLY=true` 后，信号/计划只针对自选（其余行情/简报/研究仍覆盖全市场）。

- **涨跌颜色**：红涨绿跌（默认）/ 绿涨红跌；影响价格、涨跌幅、变化值，不影响告警级别与状态徽标。
- 偏好保存在浏览器 localStorage；也可用 URL 指定：
  - `/?theme=light`、`/?theme=sepia`、`/?theme=auto`
  - `/?updown=green`（绿涨红跌）、`/?updown=red`（红涨绿跌）

## 15. 历史趋势查看

- 点击以下位置会弹出历史趋势：
  - 「重点关注」卡片的名称或价格；
  - 「市场快照」表格的代码、名称或价格；
  - 「利率与流动性」任一利率卡片。
- 弹框支持区间：1 月 / 3 月 / 6 月 / 1 年 / 2 年 / 5 年 / 全部。
- 显示最新值、区间变化、区间涨跌、区间低/高、样本数；日频数据按最后一个数据点向前截取。
- 数据来源：期货/股票日线走 `MarketBar`；利率走 `MacroObs`（含 SOFR/EFFR 及利差）。
- 外盘期货/现货日线来自新浪 GlobalFuturesService（约 15 分钟延迟），外汇日线来自 Frankfurter（ECB 参考汇率）；若图表为空，先运行 `collect_daily_bars`。

## 16. 持仓结构

- 上方表格为**品种聚合**：多头持仓、空头持仓、净持仓、净占比、多空变化。
- 下方「会员持仓明细（Top 20）」用品种下拉切换，左右两列分别列出**多头/空头**排名、会员简称、持仓、增减。
- 数据日期以表格下方说明为准；来源为上期所/郑商所/大商所会员排名表。
- 采集任务：`collect_positions`；接口：`/api/positions`、`/api/positions/members?product=au`。

## 17. 市场快照排序

- 「市场快照」拆成 **外盘品种** 与 **国内品种** 两张表，不再混排。
- 类别顺序参照 TradingEconomics 商品页：能源 → 金属 → 农业 → 工业 → 指数/个股 → 汇率；无该类别品种时自动隐藏该分类行。
- 品种顺序按 TE 页面映射，例如金属为黄金 → 银 → 铜 → 铁矿石，工业为铝 → 锌 → 镍，农业为豆 → 棕榈油 → 棉花 → 白糖。
- 外盘/国内按交易所与标的判定：上期所/能源中心/大商所/郑商所/A股归国内，其余归外盘（含 LME/COMEX/美股指数/汇率）。
- 点击代码、名称或价格仍可打开历史趋势。

## 18. 简报弹框

- 「简报」区提供 **日报 / 周报 / 月报** 三个按钮，点击后在弹框中展示；不再占用页面正文。
- 弹框头支持「打印 / PDF」「导出 Markdown」。
- 简报中的主次动力、重点关注均为表格；一句话主线使用大号加粗强调。
- 弹框宽度与页面内容一致；「重点关注」与「市场快照」前两列均为 **品种 | 代码**，代码不加粗。
- 涨跌幅按设置的红涨绿跌/绿涨红跌着色；品种名/代码用强调色加粗。
- 主题与涨跌颜色在右上角 ⚙ 设置中调整。

## 19. 利率与流动性排序

- 日报「利率与流动性」按国家分组列示：**美国 → 中国 → 日本 → 德国 → 法国 → 其他国家**。
- 同一国家内按期限从短到长；美国先列 SOFR/EFFR/利差，再 2Y→5Y→10Y→30Y 与通胀/实际利率。
- 法国为 ECB 收敛利率月度数据（FR10Y），其余国家为日频。
- 看板利率卡片顺序与日报一致。
