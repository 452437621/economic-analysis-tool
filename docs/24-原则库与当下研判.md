## 1. 原则库的方法论

### 1.1 一条原则要满足什么才能进库

| 门槛 | 要求 | 反例（不许进库） |
|---|---|---|
| **有出处** | 来自书籍原文、作者公开表述，或经历史样本检验的规律 | 「大家都说黄金抗通胀」 |
| **可观测** | 能绑定至少 1 个具体指标/公式 | 「市场情绪脆弱」 |
| **可执行** | 能转成信号或检查项 | 「要保持谨慎」 |
| **可证伪** | 写明什么情况下它失效 | 「长期一定有效」 |
| **有时效标注** | 标注适用的制度环境（金本位/固定汇率/法币浮动） | 把 1930 年代结论直接用于 2026 |

### 1.2 标注体系

沿用研究笔记的约定：

| 标记 | 含义 |
|---|---|
| **【原文】** | 达利欧书/文原话，附链接可核对 |
| **【访谈】** | 作者公开访谈/长文，注明日期 |
| **【推断】** | 本工具为工程化所做的映射，**不是作者原话** |
| **【未核实】** | 仅有二手转述，接入产品前须补齐 |
| **【争议】** | 学界存在实质分歧 |

### 1.3 原则 → 规则 → 信号 的三级落地

```
原则（文字）→ 规则（可计算，method_registry 登记）→ 信号（触发告警/进入简报）
                ↓
          影子测试 ≥20 交易日 → 有正贡献才上线 → 版本 R-YYYY.MM
```

不可计算的原则降级为**人工检查项**（checklist），每周复盘时逐条打勾，不允许伪装成信号。

1. 30Y 是否站上 5.8%——S1 的确认线；
2. 黄金与实际利率的相关性能否维持负值——D1 是否持续失效（先完成 3,864 vs 4,065 的数据对账）；
3. DXY 在 5%+ 利率下能否突破 106——美元信用是否开始定价；
4. HY OAS 是否从低位走阔 100bp 以上——S3 的前兆；
5. **2027-01-10 中美关税休战到期**——续期还是升级，是 B7「经济战」节奏的直接读数；
6. FOMC 10-2 票分歧（两位委员主张加息）——政策转向的早期裂缝；
7. 2026-11 中期选举后的财政路径（减税延期/支出法案）——S1 的加速器。

> 规则必须进影子测试：连续 20 个交易日只记录不告警，统计「触发后 3 个月资产方向」的命中率，≥55% 且样本 ≥8 次才正式上线。

## 5. 决策检查清单（给使用者）

在做出任何基于本工具的判断前，逐条自问：

1. **我依据的是哪个周期？** 长债务（年）还是短周期（月）？两者结论是否冲突？
2. **置信度多少？** <0.5 时我是否只是在表达偏好？
3. **反对证据是什么？** 我有没有认真看「为什么我可能错了」那一栏？
4. **什么数据会推翻我？** 写下来，设提醒。
5. **如果错了，损失多大？** 仓位与止损是否与置信度匹配？
6. **这是不是叙事偏差？** 我是不是先有结论再找证据？

> 工具不能替你做决定，它只能让你**更早发现自己错了**。

## 7. 诚实边界

1. 以上判断基于**达利欧框架的工程化映射**，框架本身是解释性的，不是可证伪的量化模型；
2. 2026 年的达利欧表态多为**媒体转述**，未见英文原文，引用时须写「据报道」；
3. 部分历史阈值（300% 债务、10 年战争窗口、倒挂领先期）来自金本位/固定汇率时代，直接套用有风险；

5. 概率是**条件判断**，不是频率承诺；S1–S4 加起来是 100%，不代表世界只有四种可能；
